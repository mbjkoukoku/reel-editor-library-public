# はじめての利用ガイド

**A07は、見本サイトで依頼文をコピーし、LPと一緒にCodexへ送るところから始めます。**
初回設定もその依頼に含まれます。管理する方はURLを渡し、作る方は台本確認後に素材を送ります。

## 管理者の準備

サイトと編集ルールの配布元は、招待なしで閲覧・取得できます。相手のGitHubユーザー名やメールアドレスを集める必要はありません。

### 01 ライブラリーのURLを渡す

次の文章を相手へ送ってください。

```text
動画編集ライブラリーはこちらです。
https://seitai-reel-library.ryo60129109.chatgpt.site/

A07の見本を確認し、「この見本で依頼文を作る」→「依頼文をコピー」を押してください。
コピーした文章と店舗のLPをCodexへ送ると、初回設定の確認と台本・場面表の作成を進めます。
内容を確認したら、施術者・院内の素材動画を同じタスクへ送ってください。
患者さん役の素材は用意しなくても大丈夫です。有料生成が必要な場合は、内容と費用を確認してから進めます。
サイト閲覧と編集ルールの取得に招待やGitHubログインは不要です。
```

**ここまでできたらOK：** 相手がA07の完成例を見て、依頼文をコピーできた。

配布元の変更は管理者が行います。URLを渡した方に、ライブラリーを書き換える権限まで付くわけではありません。

## 作業者の準備

動画を作る方が、自分のパソコンで行います。A07は依頼文とLPだけで台本作成を始められます。実際の動画編集へ進むときに、CodexがChatCutの接続・フォント・保存先を確認します。A04・A06は最初から動画編集を行うため、元音声付き素材と接続も先に準備します。

## 毎回の制作

A07は初回も、サイトの依頼文をコピーしてLPと一緒に送れます。初回設定のために別のタスクへ分ける必要はありません。接続を反映するために新しいタスクが必要な場合だけ、Codexが確定台本・素材・進捗をまとめて案内します。

**1本の制作につき、タスクは1つ。** 依頼文・台本・素材・修正は、同じタスクへ送ります。

<div class="production-flow" aria-label="制作の共通の順番"><span>見本を選ぶ</span><b>→</b><span>必要なものを送る</span><b>→</b><span>編集・確認</span><b>→</b><span>MP4保存</span></div>

選んだ見本で、送るものが変わります。

| 見本 | 最初に送るもの | その後の流れ | 完成動画の音声 |
| --- | --- | --- | --- |
| A01・A02 | LP＋依頼文 | 台本確認 → 素材動画＋使用する音声 | 支給音声・本人の元声を使用 |
| A03「施術風景・縦書きテロップ」 | LP＋依頼文 | テロップ台本確認 → 素材動画だけ | 全音声なし |
| A04「発話テロップ・白い角丸背景」 | 依頼文＋元音声付き素材動画 | 不要なフィラー・長い間・明らかな言い直しを整理 → 完成文と語頭語尾を再監査 → 残る発話をテロップ化 → 文字・音・末尾を確認 | 素材の元声＋短いSFX |
| A05「施術前・施術後のビフォーアフター」 | LP＋依頼文 | 短い画面テロップ・院名・配色の確認 → 対応する前後の素材 → 比較ラベル・顔モザイクを確認 | AI音声・BGMは生成しない。元音声は今回の指定に合わせ、音声なし指定ではミュート |
| A06「話の要点・コーラル帯デザイン」 | 依頼文＋元音声付き素材動画。LPは任意 | 発話を分析 → 短い要点を見本のデザインへ配置 → 画面・元声・顔モザイクを確認。逐語字幕は付けない | 素材の元声。新規AI音声・BGM・効果音は追加しない |
| A07「患者目線・1日Vlog」 | 依頼文＋LPまたは確認済み店舗情報 | 画面台本・場面表を確認 → 施術者・院内素材を送付 → 患者役素材をこちらで調達・生成して編集 | 利用できる見本のBGM・効果音を控えめに配置。新規AI音声は不要 |
| A08「院紹介・明朝帯＋本人の案内」 | 依頼文＋LPまたは確認済み店舗情報 | 前半画面台本・後半撮影用案内文を確認 → 施術・検査と本人の呼びかけ素材 → 比較して編集 | 本人の元声を保持。新規AI音声不要。有料生成は追加しない |

### 01 見本を選び、必要なものを送る

1. [見本を選ぶページ](https://seitai-reel-library.ryo60129109.chatgpt.site/#request)でA01〜A08から選びます。
2. **依頼文をコピー** を押します。
3. 新しい制作タスクへ貼り、A01〜A03・A05・A07・A08なら店舗のLP・ホームページURL、A04・A06なら元音声付き素材動画を一緒に送ります。A06で院名や予約先を表示したい場合は、LPも任意で添えられます。A07・A08はLPの代わりに確認済みの店舗情報を送っても構いません。

**A01〜A03はLPと依頼文から台本を確認し、A05は画面テロップ・院名・配色を確認して、その後に素材を送ります。A04とA06は最初から素材を送り、②を飛ばして③へ進みます。** A07は画面台本と場面表を確認してから、施術者・院内の素材を送ります。患者役素材はこちらで調達・生成するので、患者素材の提出は必須ではありません。 A08は前半の画面台本と後半の撮影用案内文を確認してから、施術・検査と本人の呼びかけの元音声付き素材を送ります。素材をすでに送っていれば後半はその発話を使い、承認済み内容の確認を繰り返しません。新規AI音声は不要です。 A04にLP・読み上げ台本・AI音声の準備は不要です。A06も読み上げ台本・AI音声は不要で、LPは任意の店舗情報確認用です。素材がまだない場合は、元音声付き素材を用意して同じタスクへ送ってください。

サイトが開けない場合は、同梱の [A01](requests/A01-reference.txt)・[A02](requests/A02-reference.txt)・[A03](requests/A03-caption-only.txt)・[A04](requests/A04-speech.txt)・[A05](requests/A05-before-after.txt)・[A06](requests/A06-speech-design.txt)・[A07](requests/A07-patient-vlog.txt)・[A08](requests/A08-promo-speech.txt)の依頼文を使えます。

A03を短い文章で頼む場合は、次をコピーしてください。

```text

LP：［店舗のURLに書き換える］
まず画面に出すテロップの台本だけ作り、私の確認を待ってください。
見本の文章・順番の大枠を保ち、店舗ごとに異なる事実を確認して差し替えてください。素材内の会話と、画面で伝える内容は分けます。
台本確認後に素材動画だけ送ります。全音声なしで編集するので、AI音声・BGM・音声の提出は不要です。今は動画編集を始めないでください。
```

**ここまでできたらOK：** A01/A02は読み上げ用の台本とテロップ案、A03は画面に出すテロップ台本が届いた。A04は依頼文と元音声付き素材動画を送れた。A05は画面テロップ・院名・配色案が届いた。A06は依頼文と元音声付き素材を送れた。A07は画面テロップ台本と場面表が届いた。A08は前半の画面台本と後半の撮影用案内文が届いた。

### 02 台本・画面テロップを確認する（A01〜A03・A05・A07・A08）

院名・地域・施術内容・価格・最後の案内を確認し、修正は同じタスクへ伝えます。A01〜A03の台本は見本の文章や順番の大枠を保ち、今回の店舗の事実に合わせて必要な部分だけ差し替えます。A05は前後の表示ラベルと今回の確認済み情報で短くまとめます。

- **A01/A02**：読み方も確認します。内容が決まったら、普段使っている音声作成ツールでAI音声を用意します。用意済みの音声や本人の元声を使う場合は、作り直す必要はありません。
- **A03**：画面で伝える内容を確認するだけで大丈夫です。素材内の会話をそのままテロップにはしません。音声は作らず、次へ進みます。
- **A05**：短い画面テロップ、院名の表記、LPから選んだ配色を確認します。まだ届いていない素材の結果や改善度は台本に入れません。読み上げ用の台本・AI音声は作らず、次に前後の素材動画を送ります。
- **A07**：日常から来院までの画面テロップと時刻、利用者が送る施術者・院内素材、こちらで用意する患者役の場面を確認します。患者役は1本内で同じ人、別の動画では別の人にします。有料生成を使う場合は本数・秒数・モデル・費用を確認し、許可した範囲だけ実行します。読み上げ台本・AI音声の準備は不要です。
- **A08**：前半の院紹介テロップと、後半に本人が話す案内文を確認します。地域・施術内容・割引・予約先は今回の情報へ合わせます。元音声付き素材が届いている場合は、その実発話を根拠にします。新しいAI音声は作らず、確認した案内を本人が話す映像と施術・検査素材を同じタスクへ送ります。

**ここまでできたらOK：** 台本が決まった。A01/A02は使用する音声も用意できた。A05は画面テロップ・院名・配色が決まった。A07は画面台本・素材の分担・患者役の準備方法が決まった。A08は前半の画面文と後半の案内内容が決まった。

### 03 素材を使って編集を進める

同じ制作タスクへ、施術・問診・検査などの動画を送ります。添付でも、パソコン内の保存場所の指定でも大丈夫です。A04・A06は①で依頼文と素材を送っていれば再送や追加の依頼は不要で、編集後に④へ進みます。以下の例文は、選んだ見本の編集を依頼する際に使えます。

**A01/A02：素材動画と音声を送る**

**A03：素材動画だけを送る**

