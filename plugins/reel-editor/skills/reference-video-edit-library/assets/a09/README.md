# A09 承認済み描画設定（0.11.2）

1制作で完成承認された近似描画を共有する。見本の元フォント・編集プロジェクト・プリセットではない。人物、写真、音声、店舗情報は同梱しない。

## 使い方

1. [制作手順](../../references/a09-approved-workflow.md)と[設定](approved-profile.json)を読む。今回の利用可能なフォントを確認する。本文はNoto Sans JP 900、縦明朝・金文字はNoto Serif JP 900を使用した。元見本と同一書体ではない。明朝は既存assets/a08-fontsのNotoSerifJP-Blackとライセンスも参照できる。フォントが解決できないまま承認済みの字形を再現したと報告しない。
2. 利用環境に合うChatCutのmotion graphicsスキルを読み、JSXを今回のプロジェクトへ登録する。`a09-text.jsx`の`item.props`へ`textProps`と該当presetを渡し、text・cx・cy・改行・強調語・動きをcueごとに設定する。呼び出し時の必須プロパティを省略しない。`accents`はJSON文字列（例：`{"動き":"yellow"}`）。登録で発行されたIDを使い、以前のプロジェクトIDを使わない。
3. `a09-photo.jsx`は今回アクセスできる同じ写真をimageIdへ渡す。写真を新規生成するコードではない。段ごとの高さ・配置・開始・方向・secondsを資料で合わせる。`a09-link-direction.jsx`はリンク誘導用の下向きの指と院名だけを描く。赤い案内と緑の「下のリンクから」は別の文字レイヤーで配置する。
4. 1080×1920基準。別解像度ではレイヤー全体を同倍率で換算する。長文を小さく押し込まず、意味単位でcueを分ける。各素材の開始・長さは今回の動作・元声に合わせ、固定32秒や前回の完成尺へ伸縮しない。

## 太さ・動きの注意

SVGのstroke幅は輪郭の両側へ出る。本文の40→27→4pxは外から白・黒・塗り色で、白外縁約6.5px、黒内縁約11.5px。単一の40px黒縁ではない。金文字は白→濃茶→金の塗り、赤CTAは白→黒→白→赤。色ごとの処理を単一スタイルへ統合しない。

動きは秒で計算する。横移動700px、残像6段（0.012秒刻み）、歓迎は中央の小文字から左の縦列へ0.43秒、金コースは3.4倍から定着へ0.42秒、オレンジは下から0.30秒、金価格は0.22秒ワイプ。コードのkind/colorによる優先処理を保つ。小字幕は入場なし。これらは承認された近似値で、元編集データの実測値ではない。

この制作環境ではSVG clipPathを本文に適用すると文字が消える不具合があった。承認済みコードは外側divの幅とoverflowでワイプする。未使用clipPath定義は残るが描画には適用しない。全環境でSVG clipPathが非対応という意味ではない。登録成功だけで完了せず、入場途中と定着の実合成で文字の存在・縁・改行を確認する。

## 変更時の確認

JSXは承認済み出力のコードからそのまま取り出した。設定ファイルの文字presetは完成承認プロジェクトの実プロパティから店舗文・強調語を除いて抽出したもの。本文・縦文字・歓迎・金文字・料金・大小の赤CTA・緑リンク・本人小字幕・条件小字幕を分ける。位置は同じ文字組みの起点で、今回の改行と背景に合わせて確認する。将来コードを変えたら代表的な本文・金文字・縦文字・CTAの入場途中と定着をネイティブ合成で再確認する。写真・音声の再利用許可や他環境での動作は、このコードの承認から推測しない。
