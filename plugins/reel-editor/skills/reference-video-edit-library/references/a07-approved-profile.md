# A07：完成承認版の制作基準（0.10.5）

2026-11-10に利用者が完成承認したA07の文字・音・施術後の流れを、新しい制作へ引き継ぐ。元見本 `ex患者vlog2.mov` の観測値は [a07.json](a07.json) の `reference`・`graphicStyle`・`referenceScriptOnly` に保持し、**制作では `productionDefaults` を優先する**。元フォントの完全同定ではなく、利用者が承認した再現版である。

## 同じ文字サイズと余白を使う

すべて1080×1920・30fpsを基準にする。

| 役割 | フォント／太さ | 文字サイズ | 行送り | 字間 |
|---|---|---:|---:|---:|
| 本文・分割帯 | A07 Reference Serif／700 | 78px | 104px | 4.8px |
| 時刻 | Noto Serif CJK JP／900 | 75px | 100px | 5px |
| 導入の地域・主題・Vlog | A07 Reference Serif／700 | 100／84／92px | 126／106／111px | 0 |
| 終盤の院情報 | A07 Reference Serif／700 | 90px | 118px | 3px |
| 終盤の上段見出し | Noto Serif CJK JP／900 | 80px | 100px | 4px |

本文は白・中央揃え、黒影は右5px／下7px／ぼかし1px／不透明度0.7。帯は角丸なし、`#222222`・不透明度0.5。本文の中心はx540・y960、最大幅1000px、内側余白は上14・左右22・下16px。調べる場面は本文中心y932、時刻の上端は基本y616・院内場面y652を使う。小窓画像と本文の間には22px以上、2本の帯の間には24px以上の余白を確保する。本文・時刻を大きな合成画面で確認し、人物や手元との重なりだけ必要に応じて微調整する。

本文72→78pxは約8.3%拡大、行送り78→104pxで余白を増やした。導入と終盤も個別に調整しているが、時計は保持しているため「全要素を一律8%拡大」とは説明しない。旧72px・行送り78pxへ戻さない。

本文は原則2行以内、終盤の院情報は最大3行とし、長い文は意味のまとまりで次のテロップへ分ける。A08の1行8文字制限を混ぜない。文字サイズ・行送りを縮めて押し込まず、承認サイズの実字形で改行と表示時間を決める。分割帯は自然に下へ伸びる列配置を保ち、1帯目が長くなっても2帯目へ重ねない。

終盤はx中央・y903、幅932px・最小高さ330px、`#E88721`・不透明度0.75の帯。本文90px／行送り118pxで現在の院名・アクセス・予約案内だけを入れる。導入の下2段は約0.6秒の文字出現、そのほかは静止した文字・帯とハードカットを基本にし、派手な追加動作を入れない。同じ比率の別解像度では文字・行送り・影・帯・余白・座標を同倍率で換算する。

## 台本と動作を先に対応させる

最初にLPと依頼文から、画面テロップ・時刻・場面・目安尺・担当・既存素材の可否を表にする。生成候補は「開始状態 → 必要な動き → 終了状態」まで具体化する。起床なら、横になっている状態から起き上がり、ベッド端へ座り切って足が下りるところまでを指定し、実際に完了しているか確認する。途中で終わる素材を採用したり、長い停止で尺を埋めたりしない。

朝の家事後に院を調べる場面は **12:00を基本**とし、13:00など台本に自然な時刻も使える。原見本の22:00を昼の場面へ流用しない。朝食・洗濯の動作が極端に遅い場合は自然に見える速度へ調整し、手指・布・前後のつなぎを確認する。起床後に背中を向けたまま止まる余分な部分は切る。調べる場面の足組みは、顔やスマホと本文を残す範囲で見えない構図へ整える。承認した場合は同じ起床素材を2場面へ使え、必要のない追加生成を行わない。

施術後は次の感情の順序を残す。各文は**架空の患者役による承認済みストーリー例**であり、実在患者の証言や確認済み効果ではない。

1. 「家に帰って
いつもの家事」
2. 「あれ、腰が軽い
家事も楽にできる」
3. 「また旅行に
行きたくなってきた」
4. 「来てよかった」
5. 今回の院情報・予約案内

新しい制作でも「帰宅して日常 → 楽になった感情 → やりたいことへの意欲 → 来てよかった」という構成を台本に反映して確認する。単なる相談案内だけへ置き換えて感情の流れをなくさない。今回の院の事実はLPや確認情報に合わせ、架空の人物を実患者本人や全員に同じ効果が出る証拠として扱わない。約48.83秒・特定のカット数・患者像・症状・院名を固定しない。

完成承認版では、左下の「AI生成映像」やサンプル表示は入れない。既定の `sceneLabel` と `sampleLabel` は空文字。架空人物であることは制作記録・最初の台本で区別し、今回の素材ライセンスや利用者の表示指定がある場合はそれに合わせる。完全な架空人物へ患者匿名化のモザイクは自動で付けない。実在患者は共通の顔モザイク手順を使う。

## BGMと効果音

A07は承認版と同様、**静かめのBGMと場面に同期する短い効果音を既定で入れる**。新規AI音声は作らない。今回の利用範囲で許可され、アクセスできる見本原音があれば優先する。以前の広告1本での許可を、別店舗・別利用者への包括許可や音源の再配布許可とは扱わない。今回すでに確認済みの許可は再確認せず引き継ぐ。

| 場面 | 音の役割 |
|---|---|
| 最初の起床・翌朝の起床がある場合はその場面にも必須 | 「ピピピ」のアラーム |
| 家事カットの切替 | 短い切替音 |
| LP／院プロフィールの小窓 | 小窓の出現音 |
| 施術者の小窓 | 2つ目の出現音 |
| 到着・相談開始 | 短いアクセント |
| 帰宅・家事へ戻る | 短いアクセント |
| 最後の院案内 | 締めの音 |

完成例はアラーム2回を含む8配置だったが、各場面の役割へ同期し直し、秒数や回数を機械的に固定しない。ファイル冒頭ではなく、音が実際に鳴り始める位置を映像・文字・小窓の切替へ合わせる。

承認例の原音由来BGM床は再生速度1倍、終端1.2秒フェードアウト、ゲイン-3dBで約-32.43LUFS、アラームの目安ピーク-18dBFS、短い切替音は約-16dBFS。これは同じ原音を使う場合の開始値で、別曲へ同じゲインを貼る指示やSNSの規格値ではない。音色・余韻・主張の強さを実際に確認し、BGMを前に出しすぎない。

音源の取得元は、利用者がアクセスできる [ライブラリのA07見本](https://seitai-reel-library.ryo60129109.chatgpt.site/assets/a07-reference.mp4)、または提供された `ex患者vlog2.mov` を使う。共有プレビューは原本のAAC内容・時刻を保持して登録されているが、取得した版を確認してから下記の秒数を使う。閲覧権限と今回の広告利用許可は別である。取得できない場合は、取得したと装わず、必要な許可済み原音を案内する。

同じ原見本を正当に使える場合、効果音の抽出元区間は次を参照する。これは原見本の秒数であり、新しい作品の配置時刻ではない。

| 原音の役割 | 原見本からの抽出区間（秒） |
|---|---:|
| alarm | 0.08〜0.70 |
| shopping／家事の切替 | 11.50〜11.90 |
| inset1／LP小窓 | 17.45〜17.85 |
| inset2／施術者小窓 | 18.98〜19.38 |
| arrival／到着 | 29.00〜29.46 |
| return／帰宅 | 46.89〜47.29 |
| closing／院案内 | 58.22〜58.75 |

抽出時の短い端処理は入り0.003秒・終わり0.020秒が参照値で、音の頭と余韻を含めて確かめる。翌朝がある場合は同じalarmを必ずもう一度配置する。買い物の場面がなければ承認例と同じく短い家事切替へ役割を合わせられる。

BGM床の再現手順は `a07.json.productionDefaults.audio.referenceBgmReconstructionRecipe` に保存した。48kHz・2chのfloat PCMへデコードし、テンポとピッチを変えず、原音に入っている短い効果音の箇所を同位相の音楽部分で置き換える。確認した繰り返し間隔は約21.333333秒（約90BPMの32拍＝4拍子8小節）。置換の両端は45msのsmoothstepブレンドを使う。始まりの0〜0.70秒は音楽がまだないのでアラームだけを除き、約1.53秒から始まる原本の音楽の位置は保持する。

| 家事切替音 | 11.495〜11.770 | 11.450〜11.815 | 32.783333〜33.148333 |
| 小窓1 | 17.490〜17.770 | 17.445〜17.815 | 38.778333〜39.148333 |
| 小窓2 | 19.010〜19.290 | 18.965〜19.335 | 40.298333〜40.668333 |
| 翌朝のアラーム | 23.090〜23.670 | 23.045〜23.715 | 44.378333〜45.048333 |
| 到着音 | 29.005〜29.340 | 28.960〜29.385 | 50.293333〜50.718333 |
| 帰宅音 | 46.880〜47.180 | 46.835〜47.225 | 25.501667〜25.891667 |

原音全体から処理して今回の尺に合わせて切り、再生速度1倍・ゲイン-3dB・最後1.2秒フェードを開始値とする。承認例より長くする場合は、後半に残る原本の締め音なども確認して、同位相の置換可能な箇所を検証する。元例の約48.83秒に固定しない。音楽だけの完全な分離ではないため、混合後の音量とつなぎを確認する。

BGMと効果音が混ざった原音を編集する場合は、音楽の流れを連続させ、短い音源を重ねた箇所でBGMを二重にしない。混合音の抽出は完全に分離された効果音とは限らない。短いフェードで頭や余韻を切らず、波形・ピーク・重複・つなぎと実際の試聴を分けて確認する。元音源を取得できなければ今回使える提供音源や無料の近い音を選び、原音とは違うことを伝える。有料生成や購入へ無断で切り替えず、音なしの明示指定は優先する。

## 最終運用の補足（0.10.7）

- 文字が読み取れる状態になってから読む時間を確保する。映像と文字の切替は独立して決め、長文は意味単位で分ける。文字縮小・不自然なスロー・停止画面で尺を合わせない。
- 採用尺は必要な動作の完了を含める。必要な終わりが素材にない場合は、速度変更やクロップで完了したように見せず、不足として代案を示す。同じ起床素材の初日・翌朝への再利用は、承認済み構成と服装・時刻が自然なら改めて許可を求めない。
- 有料生成は、生成前の場面表と予算内で実行する。送信後の応答が曖昧ならジョブの状態を確認し、同じカットを重複送信しない。生成のジョブID・元の秒数・採用箇所・見積クレジット・確定消費・未採用理由を案件内へ残す。2か所への共用は生成2本と数えず、編集の配置数と生成本数を区別する。確定料金を見積もりや残高差だけから推定しない。
- 完成確認は本文2行、分割帯、小窓、最後の3行と動きの区切りを含める。修正版では指定外の文字サイズ・行間・音を保ち、今回のMP4を確認する。元見本と承認基準の違い、素材不足による代案だけを短く報告する。

導入に必要な手順は[first-use.md](first-use.md)にまとめている。0.10.7で承認された見た目を再変更したものではない。サイトの承認版プレビューは圧縮した閲覧用であり、文字の制作値・音の復元は本資料と同梱資産を使う。
