## 見本の画像・素材動画をそのまま使う（0.11.1）

A09は見本で使われている差し込み画像・素材動画をそのまま使う。同じ構成・画像・映像の順番、使用区間、トリミング、配置、出現タイミングを基準にし、別の写真・ストック映像・AI生成へ自動で置き換えない。店舗固有の文言など今回変更が必要な部分だけを分け、映像を差し替えるのは利用者が指定した箇所に限る。

利用可能な元画像・元動画・編集プロジェクトを先に確認する。完成版YouTube映像は文字が焼き込まれた合成映像であり、編集可能な元素材一式ではない。変更しない区間は元映像を保てるが、焼き込み文字を変更する区間で元画像・文字なし動画・編集データが見つからなければ、不足する原素材だけを案内する。見本に似た別素材へ無断で代替せず、生成による消去・復元を原素材そのものと説明しない。既に使える素材の再提出や撮り直しは求めない。

この素材方針は、以下の新素材選び・不足素材の代替より優先する。新規撮影や別素材への置換を標準工程にしない。院名・価格・予約先などの事実と、映像に出ている人物・医院の所属は区別し、別店舗の実患者の成果だと新たに断定しない。

## 今回の入力と進め方

見本を登録する依頼だけなら、LPや新素材を要求せず登録で完了する。実制作では、最初に今回のLPまたは確認済み店舗情報から「画面テロップ／前半のナレーション案／後半に本人が話す案内文／必要な場面」の表を作る。原見本の役割順と語りの運びを保ち、店舗固有の事実だけを正しく差し替える。後半の動画が既に届いていれば実際の発言を使い、撮影用の文を本人が話したことにはしない。

台本を提示したら「内容をご確認ください。決まったら見本と同じ画像・素材動画で編集します。文字変更に必要な原素材や、指定の差し替え素材が不足する場合だけご案内します」と伝える。承認済みの台本と必要素材が揃い、編集も依頼されていれば再承認で止めない。全編の文字起こしや、新規AI音声の生成が前提のパターンではない。有料生成は内容・本数・秒数・費用を示して許可された範囲だけ使う。

## 文字のトレース

`a09.json` の `typography` と各cueの `bboxApproxPx` を使う。値は1080×1920の完成画面上の計測と描画開始案であり、元編集ソフトのフォント設定値ではない。元フォント・ウェイト・アニメーションのプリセット名は未同定。近似候補は原見本の同じ文字で字形を比較して選び、同一書体と説明しない。

- 冒頭：太い明朝の赤〜暗赤、白縁、黒いぼかし影。右列と左下の補足を別レイヤー。縦列の文字方向・句読点を保つ。
- 3段写真：写真ごとの明朝ラベルを残す。写真は一度に出さず段階的に覆う。中央の赤縦書きは独立した前面レイヤー。
- 歓迎：紫〜ピンクの太い縦書き、白縁と黄色の発光。中央の小さい状態から左の大きい列へ移る。
- 本文：見かけの字高約112–125px、中央Y約1010px、2行の行送り約145pxが起点。塗り→黒い内縁→白い外縁の順。帯は付いていない。赤・黄色・水色は単語単位に設定する。
- 「正しく動ける／身体を目指して／いきます」は3行の見本。A08の1行8文字・最大2行や、A07の明朝帯へ変換しない。
- 後半：本人導入の小さい白文字、金色グラデーションの太い明朝、オレンジのキャンペーン、金色の価格と下向き矢印、赤い案内・緑のHPを役割ごとに使い分ける。価格は上の案内より遅れて表示する。
- 最後：検索欄・検索ボタン・カーソル・3つの下向きの指を別レイヤー。指は点滅、カーソルは検索欄へ移動する。元の院名を残さず今回の表示名と実際の予約先に置換する。

行数・改行・意味の区切りをcue単位で保つ。長い新しい院名などを小さく縮めて押し込まず、必要なら表示区間を分ける。原見本には左右に迫る文字があるが、新しい文の文字や縁を画面外へ切らない。別解像度では全体を同比率で換算して合成を確認する。

## 動きと背景を別々に配置する

写真の横スライド、縦文字の拡大・残像、説明文の横ブラー、短いワイプ、金色文字のズーム、オレンジ文字の下からの出現、CTAの拡大と点滅を `captions[].motion` から再現する。推定の開始値で配置し、前・途中・定着のフレームを見本と比較する。元プリセットを特定できたとは扱わない。

施術映像の切替には約0.3–0.4秒のクロスディゾルブが見える。背景のカットと字幕変更は独立している。22.67・25.23・28.23秒などの自動検出は文字変更にも反応しており、本人映像をそのたびに切らない。A01/A02の固定cue伸縮helperへ渡さず専用の編集計画で配置する。

## 音声・料金・店舗の事実

前半は別ナレーション、後半は本人の呼びかけとして分ける。支給ナレーションを使う場合は発話の長さを基準に画面文を同期し、後半は声と口を保つ。本人声の不要フィラー・言い直し・長い間を整理する場合だけ [発話整理](speech-cleanup.md) を使う。施術中の必要な動作を無音だけで削らない。

原音はASRと混合音量を確認したが、BGM・効果音の曲名、個別音、直接試聴は未確認。音の種類やプリセットを想像で確定しない。新しい制作では使える支給音を優先し、なければ利用可能な無料音源を実際に確認して声を妨げない音量へ調整する。元見本のミックスのtrue peak約+0.23dBTPを制作目標にせず、出力のピークと聞きやすさを確認する。音声・BGM・SFXは別トラックで後から調整可能にする。

原見本のコース名、10,000円→1,980円、院名、症状や施術法、患者の経歴・感想は今回の医院の事実ではない。LPと確認済み情報で置換し、確認できない結果や感想を作らない。比較部分のラベルは対応関係が確認できた素材にだけ付ける。患者顔は今回の指定を優先し、通常は[顔モザイク](face-mosaic.md)に沿って処理する。

## 編集可能な納品と確認

1. 取得できた元素材・cue・装飾・前後ラベル・検索欄・音を編集可能に保存する。元映像の焼き込み部分と、独立して修正できるレイヤーを区別する。文字を変えるときは該当レイヤーだけ更新し、声や映像の長さを勝手に変えない。
2. 冒頭縦書き、3段画像、灰色場面、歓迎、本文1/2/3行、Before/After、金色コース、価格、CTAの実際の合成フレームを見本と並べる。字形、輪郭、幅・高さ、行送り、配置、色、影を調整する。
3. 主な文字と映像の切替は直前・途中・定着を確認する。発話の切れ、動作途中の切断、患者顔の隠し漏れ、音の二重再生を全編で確認する。
4. 完成ファイルの依頼があればDesktopでMP4をローカル保存し、その書き出しで冒頭・本文・料金・最終フレームと音声を確認する。

今回の0.11.0は原見本の分析と共有登録。新店舗の素材での合成・全編試聴・MP4保存や、別利用者環境での再現成功を検証済みとは扱わない。

0.11.1では利用者の指定により、差し込み画像・素材動画を原見本と同じものへ固定する方針と、焼き込み済み映像からの編集の限界を反映した。元の画像・撮影ファイル一式の取得完了や、新しい動画の編集完了を意味しない。
