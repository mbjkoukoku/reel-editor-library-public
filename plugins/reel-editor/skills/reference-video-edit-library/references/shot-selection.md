# 言葉・動作に合う素材選びと反復の整理

複数の映像・写真を組む編集、追加素材の受領、映像の差し替えで使う。今回の明示指定と採用音声を優先し、完成承認済みの別動画へ遡って適用しない。台本だけの段階では映像案にとどめ、未確認の素材を採用済みとしない。

## 言葉から必要な画を決める

字幕・発話を意味の区切りで読み、検査、説明、施術、セルフケア、アクセス、予約案内などの役割を区別する。素材名や代表画像だけで決めず、採用候補の区間を連続して見て、対象部位・動作・視線・姿勢を照合する。例えば股関節の検査にはその動きが見える区間、セルフケアには実際の運動・実演を選ぶ。問診をセルフケアの実演として扱わず、説明用の写真ならホワイトボードや図など、その説明と関連する内容が読めるものを選ぶ。静止画でよいか、動作を見せる必要があるかも判断する。

実演が見当たらず、今回の指示で「説明でもよい」と認められる場合は、先生が資料を使う・患者へ伝えるなど、説明に適した動作のある動画区間を候補にできる。単に話を聞いている場面を自動的に代用せず、説明場面として選んだ理由を記録する。その動画をセルフケアの実演や、未聴取の元声が当該内容を説明している証拠とは扱わない。既に認められた代替方針を再確認で止めず、適切な区間がなければ不足を伝える。

案件メモには「発話／字幕と完成時刻・役割／素材と元の開始終了／画面で見える部位と動作／既使用区間・採用理由」を対応させる。本人発話を使う場面は口と声の同期を保つ。支給ナレーションの言葉を、手持ち素材へ合わせるために勝手に書き換えない。合う候補がなければその説明に必要な素材の不足を伝える。

## 追加素材と既使用の場面を照合する

追加フォルダの候補を既存タイムラインと照合し、確認済み・未確認、既使用・未使用を分ける。同じ原本の重複区間だけでなく、別ファイルでも同じ撮影・同じ動作が続いていないかを実映像で確認する。別名・拡大・左右反転・別トリミングだけで別場面と数えない。

内容に合う未使用の場面を優先し、全体を通して同じ動作や構図の不要な反復を減らす。ただし比較、振り返り、動作の連続性に意味がある再掲は残し、理由を記録する。全素材の使用、全カット別ファイル、特定の採用本数は必須にしない。未使用という理由だけで無関係な映像を入れない。

同じ原本を再利用する場合は、既使用と重ならない適切な区間を探し、直前・直後だけでなく近接する場面の動作・姿勢・構図も比較する。先生と資料へ寄せるなど意味のある構図変更は反復感を減らす補助にできるが、拡大だけで別の撮影・未使用の場面と数えない。構図差だけで内容の不一致を解消したことにせず、必要な顔・手元・資料と患者顔の保護を完成画面で確認する。

カットは一文や意味の区切りを基本に、動作の始まりと終わり、読む時間へ合わせる。今回の「5〜6秒程度」などの希望があれば目安にするが、全案件・全カットの固定値にしない。一つの説明に関連する複数カットを使ってもよい。短い指差しや長い実演を機械的な秒数で切らず、画が停滞する区間だけ適切な別場面を検討する。

## 予約案内の動作と指定位置

「下のリンク」など方向を伝える文言に、指差し素材を使う場合は、実際にその方向を示す区間を選び、案内の発話・字幕表示中に動作が読めるようにする。動き出す前の待機姿勢だけを使わず、完成画面で指先が切れていないか、字幕・ぼかしで手元が隠れていないかを確認する。適切な指差し素材がなければ無理に作らず、意味に合う案内の画か不足の報告で対応する。

利用者が指定した素材・元区間・挿入位置・移動先を優先する。「最後の映像を説明写真の直後へ」のような依頼は、移動元と移動先を先に特定し、元の場所に不要な重複を残さない。映像だけの修正では指定外の声・BGM・効果音・字幕・完成尺を保つ。移動先の長さに合わせると必要な動作が欠ける場合は、適切な元区間を再選定し、無断で音声を詰めない。

## 修正版で確認する

新しい素材・採用範囲で構図と明るさを合わせ、必要な動作と手元を残す。横素材を縦画面へ置く場合は、主映像を中央で見せ、余白にぼかした背景などを使える。天井など不要な背景を減らす場合も、説明に必要な部位まで切らない。顔モザイクは元の効果をただコピーせず、新しい時刻・位置・拡大率で[共通手順](face-mosaic.md)に従って確認する。

変更区間と前後を連続して見て、言葉と動作の一致、同じ場面の不要な反復、切替の唐突さ、指先や施術箇所の見切れを確認する。完成MP4でも対象箇所を見て、[部分差し替えの確認](media-revisions.md#部分差し替えの確認)に従い音声・字幕・尺の保持を比較する。素材一覧・未使用数・ファイル名の違いだけでは、内容の一致や反復解消を確認済みとしない。保存・合成・MP4・試聴・全編再生・利用者の承認は分けて記録する。
