# A06：話の要点・コーラル帯デザイン

0.8.0で追加し、0.8.1で新素材による初回の制作・字体比較・文字組みの完成承認を反映した。`A6`も`A06`として扱う。見本は「line_oa_chat_261022_105155.mp4」。**今回の元音声付き素材を分析し、話のテーマや要点を短い見出しへ整理して、見本の固定帯・カードのデザインを付ける。** 発話を一語ずつ字幕にするA04、原音を使わないA03、施術前後の比較を作るA05へ切り替えない。

## 入力と進め方

1. 今回の元音声付き動画を受け取り、原音と映像を確認する。素材がなければその動画を求め、見本を今回の素材として流用しない。LPは発話分析の必須条件ではない。
2. 現在接続しているChatCutホストの基本・発話編集・文字起こしスキルを読み、内部確認用の時刻付き文字起こしを作る。話者、否定、時制、質問と回答、患者本人の体験と施術者の説明を分ける。ASRの結果だけで聞き取りを確認済みとせず、見出しの根拠になる箇所を原音と照合する。
3. 文字起こしから、短い前置き・大きな主題・補足の要点を選ぶ。各文と根拠の素材時刻を作業記録へ残す。逐語字幕は画面に出さない。要約した文に引用符を付けて本人の発言として扱わず、引用する場合は実際の発言へ忠実にする。意味のある否定・条件・時制を削らない。
4. 院名・所在地・アクセス・キャンペーン・予約先を出すときは、今回のLP／公式情報またはユーザー指定で確認する。未提供でも発話分析と主題デザインは進め、未確定の院情報・キャンペーンは省くか確認待ちにする。見本の院名、駅名、症状、効果を他の動画の既定文として入れない。
5. 今回の話に合う本文帯と、確認できた場合だけ締めの案内を、元音声と施術映像へ重ねる。通常は作業内で要点案を整理して編集まで進める。「まず文案だけ」という指定や、主題・効果など判断に必要な事実が曖昧な場合は、その部分を確認してから反映する。毎回一律に台本承認待ちにしない。
6. 元の話し声と施術の流れを残す。不要なフィラーや準備の間は[speech-cleanup.md](speech-cleanup.md)に従って必要な箇所だけ整えるが、検査・施術・返答・意味のある沈黙を、音がないことだけで切らない。参考の40.54秒や32.54秒の切替へ固定せず、今回の内容に合う尺にする。
7. 患者の顔が映る場合は[face-mosaic.md](face-mosaic.md)を適用する。見本に既にあるぼかしを維持し、新素材の位置・動き・反射へ合わせて必要なモザイクを作る。帯やカードは顔隠しの代用品にしない。

`executionRoute: speech_summary_design`はこのライブラリ内の分岐名であり、ChatCut API名ではない。`timeline_plan.py`・`text_revision.py`の固定カット／字幕処理へ通さない。使用中のホストに対応するテキスト・Motion Graphicsのスキルと実在するツールを使う。過去のホストのJSX方式や未提供APIを無条件に移植しない。

## 固定帯とカードの見た目

[a06.json](a06.json)と[本文の比較画像](../assets/a06-reference/body.jpg)、[締めの比較画像](../assets/a06-reference/closing.jpg)を使う。比較画像は新しい完成動画へ挿入しない。

見本は360×640・24fpsの縦長動画。実際の施術映像を画面いっぱいに出し、その下半分へ文字の階層を重ねる。映像と施術者・手元が上側に見えるよう、素材に合わせて位置と文字量を調整する。大きな主題帯を短い間隔で入れ替える字幕動画にはしない。

- **前置き：** 白い太字、画面中央付近の帯の直上。見本の文字高は約24px。
- **主題：** コーラル色の横幅いっぱいの帯に白い極太文字。見本の帯はおよそy310〜412、文字サイズ約56px。
- **補足：** 白い細い角丸カードに黒い太字。見本はx9・y441・幅342・高さ35、文字約18px。見本が体験談でも、今回は根拠のある要点を選び、体験談や改善結果を必須にしない。
- **院の案内：** コーラルの角丸カードに、アクセスと院名を白い太字で2段。見本はx38・y509・幅284・高さ115、文字約28px／38px。今回の院情報が確認できた場合だけ使用する。

主色の画素測定は約`#FB6164`。白／黒と組み合わせる。フォントは太い日本語ゴシック系に見えるが、**正確なフォント名・元の文字サイズ・影の値は特定できていない**。0.8.1の制作では、同じ日本語の文面をM PLUS 1p、Noto Sans JP、Zen Kaku Gothic New、Dela Gothic Oneで合成比較し、利用者がNoto Sans JPの900相当を見本に最も近い近似として承認した。ChatCutのフォント一覧で利用できる場合はこれをA06の制作既定候補にするが、元書体と同一とは説明しない。別ホストで使えない場合は、実際の表示文を同じ画面へ入れて太さ・字幅・角張りを比較して代替する。

上の数値は圧縮済み360×640画像上の概算で、1080×1920など別の出力では比率を保って拡大する。LPに配色を合わせる指定があるときは、色だけを根拠のあるブランド色へ寄せ、階層・配置・読みやすさを保つ。

### 0.8.1の文字組み既定

- 文字を枠へ押し込むために負の字間を使わない。通常は字間を0〜0.02em程度の非負にし、長い文は文字サイズ・カード幅・改行を先に調整する。
- 2行のバッジ・終盤カードは、行高1.15〜1.22を目安にする。行間と字間を別々に調整し、2行の間が詰まって一塊に見えないことを原寸の合成画面で確認する。
- 小さい前置き・補足・アクセスは、左右に空きが余る場合、カードをむやみに小さくせず文字を一段大きくする。文字幅は安全な内側幅のおよそ85〜95%を目安にし、端へ触れない余白を残す。
- 大見出しは主題の文字数に合わせる。短い3〜4文字の主題は見本の約56pxより大きくしてよいが、長い診断名・話題は帯の左右余白を保って縮小する。同じ固定サイズを全案件へ強制しない。
- 院情報の2段は、アクセスと院名の間隔を独立した`gap`として確保する。行高だけで上下を詰めず、院名を最も強く、アクセスを次の階層にする。
- まずフォントを確定し、そのフォントの実字形で文字サイズ・字間・行間・カード余白を調整する。字体を後から替えた場合は、旧フォントでの改行・幅・余白の確認結果を引き継がない。

## 締めの案内

見本の末尾は、小さく傾けたコーラルの角丸バッジ、中央の白い角丸カードに黒い太字2行、下の白文字にコーラルの柔らかい光彩と3本の下矢印という構成。固定表示で、複雑な入場アニメーションは確認していない。見本では本文帯が32.4167秒で消え、3フレーム後の32.5417秒で締めの要素が一斉に現れる。この短い空白や時刻を新素材へ強制しない。

「期間限定」「初回キャンペーン実施中」は、今回の実施内容が確認できる場合だけ使用する。リンクへの案内と矢印の向きは実際の投稿先・予約先に合わせる。確認できなければ、キャンペーンやリンクを想像で作らず、その要素を省く。締めを必ず広告にする必要はない。

本人の声と既存の素材音を残し、AI音声・BGM・効果音を新規に追加しない。見本の画面文を新しいナレーションへ変換しない。

## 根拠と検証

見本のASRでは、ゴルフ・スコア・ラウンド等についての会話が候補として得られた。ただし、画面にある「薬を飲んでも変わらなかった」「脊柱管狭窄症」「ゴルフが痛みなくできるように」という全ての説明が、その音声だけで確定したとは扱わない。ASRによる候補と、人が実際に聞いて確認した内容を分ける。新素材でも、話題・映像だけから診断名、効果、治療歴を推測して追加しない。

登録時は全体の等間隔画像、本文と締めの原寸画像、切替付近の連続フレーム、最初と最後を確認した。見本の患者の顔には既存の強いぼかしが見えるが、全露出フレームの匿名性を保証した確認ではない。プレビューは映像・音声の全パケットをそのまま保持してMP4へ再格納し、全編デコードを確認した。音声の試聴、新素材の編集、ChatCutでの文字描画一致、顔の全区間処理、完成MP4、別利用者の実行は未検証。

完成時は、文字の根拠と誤解を招く引用がないか、文字切れ・重なり・読みやすさ・施術の見え方、元音声、カット、冒頭・末尾を合成画面と再生で確認する。文字組みは小さい一覧画像だけで終えず、本文の代表1フレームと終盤の代表1フレームを大きく表示し、さらに本文→終盤の境界と最終フレームを確認する。フォント変更後は、実効フォント、表示文、カードサイズ、行高、字間が保存値と一致するかを読み直す。患者顔は共通手順の全露出フレーム確認を行う。文字は修正可能なレイヤーにし、誤字修正では映像・元声・表示時刻・モザイクを維持する。字形描画を使う場合は、文字変更時に字形と配置の再生成が必要なことを明示する。書き出しを求められたら[ローカル保存](local-delivery.md)へ進み、実際に確認した範囲だけを報告する。

0.8.1の承認制作では、短い主題を大きなコーラル帯へ置き、前置き・補足・院情報を拡大し、終盤2行の行間と字間を広げた合成画面を確認した。利用者は編集結果を完成として承認した。原音の独立試聴、音声込み全編連続再生、完成MP4、全フレームの顔モザイク監査、別利用者環境の一連の実行は未確認であり、承認範囲と分けて扱う。案件固有の症状・院名・アクセス・時刻・プロジェクトIDは制作既定へ保存しない。
