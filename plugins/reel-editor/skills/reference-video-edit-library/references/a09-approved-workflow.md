# A09：完成承認後の再利用手順（0.11.2）

原見本の観測記録は[a09.json](a09.json)・[画面原文](a09-script-reference.json)、完成承認された近似描画は[approved-profile.json](../assets/a09/approved-profile.json)と[描画資産](../assets/a09/README.md)を使う。後者を原見本の数値へ上書きしない。台本だけの依頼では素材・音声・フォント・ChatCutを必須にしない。

## 今回の指定を引き継ぐ

最初に会話・承認済み台本・制作記録から以下を拾い、決まったことを聞き直さず進める。未指定は元のA09方針に従い、制作に不可欠な不足だけ確認する。

| 項目 | 判断と処理 |
|---|---|
| 台本 | 「テンプレと同じ」は語り・順番を保つ指定。院名・地域・料金だけでなく治療歴・効果・資格などの事実も確認する。画面の重複強調を読み上げへ重複させない。全文を求められたら省略せず、画面文と音声文を分けて提示する。 |
| 人物映像 | 原則は見本素材。「人物は支給動画へ差し替え」の指定があれば、人物・施術・本人案内を支給素材から選び、薬→湿布→リハビリの同じ写真は維持する。全素材使用は必須ではない。 |
| 比較 | 同一人物・動作の対応する実素材だけでBefore/Afterを作る。「比較を外す」が決まっていれば再要求せず、比較ラベルと未確認の結果表現を外して承認された施術・動作映像を配置する。他案件でも自動で比較を外すルールにはしない。 |
| 前半音声 | 今回の見本ナレーション再利用が明示承認されていれば同じ依頼で再確認しない。実際に使う音がBGM・SFX込みのミックスならそう記録し、独立したナレーション原本と扱わない。他案件の許可へ引き継がない。 |
| 本人声 | 元声と映像の同じソース区間をリンクして保持。LP案を実発話と扱わない。不要な間だけ自然に整理し、必要な語尾と指差し動作を残す。音量差は今回測定して調整し、過去のdBを固定しない。 |
| 料金 | 今回の確認済み料金と適用条件を使う。「日付・人数を表示しない」は表示指定で、期限切れキャンペーンの継続や適用対象の変更を意味しない。今回すでに料金の継続・適用条件が確認済みなら聞き直さない。 |
| CTA | Instagram広告でリンク誘導なら赤い案内→緑の「下のリンクから」→下向きの指＋院名。検索欄・検索ボタン・カーソルは置かない。広告リンク自体の設定は動画編集とは別。検索への案内が指定された案件だけ検索型を使う。 |

## 元素材がなくても変更しない部分は保つ

手元の素材・共有フォルダ・使用中プロジェクトを先に調べる。薬・湿布・リハビリの写真は元ファイルを優先。許可された見本の静止フレームに必要な写真と変更不要のラベルが完全に見えていれば、その画素を切り出して使える。元写真ではなく「焼き込みラベル込みの切り出し」と記録し、写真の順序・配置・段階的な出現を合わせる。

写真のラベルを変える必要がある、人物や文字で隠れた部分が必要、必要画素が足りない場合は、その変更箇所に必要な原画像・文字なし動画・編集データだけを案内する。同じ写真に似た別画像やAIによる消去・復元へ自動置換しない。届いた素材の再提出・撮り直しを一括で要求しない。切り出しが今回使えたことは、別の見本でも同じ処理が可能な証明ではない。

## 文字の修正と完成確認

承認済み描画資産を起点に、実際の新しい文字を合成し、対応する見本画面と比較する。文字だけの修正依頼では映像・元声・採用ソース区間・尺・モザイクを保ち、変更した文字レイヤーを確認する。変更前のコードと確認済み版を区別して残す。

定着した字幕だけでなく、写真の順次出現、文字の入場途中、切替、価格からCTA、最終フレームを見る。フォントが未解決、本文が消える、縁が切れる、手や顔と重要文字が重なる場合は調整する。患者顔は移動・横顔・反射・切替・拡大を含めて確認する。声と口の同期、発話の欠け、ミックスの音量・ピークを確認する。静止画や数値確認だけを「全編を人が試聴済み」と書かない。

## 承認後の納品

ChatCutの編集プロジェクトとローカルMP4を保存し、最新承認版を特定する。外部の素材やJSXへの参照が残る場合、プロジェクトファイル一つを全素材同梱の持ち運び可能版と説明しない。

利用者から共有フォルダへの保存を頼まれたら、その指定フォルダに最新承認MP4をアップロードする。Google Driveスキルを読み、利用できる接続ツールを優先する。ローカルファイルを直接渡せる機能があれば利用し、未対応なら適切な方法を調べる。視聴承認だけから外部公開の許可を推測しない。既存の同名ファイルを確認し、無断上書きや重複を避ける。

指定がなければファイル名は `【編集済み】A09_院名_YYYYMMDD.mp4`。受取先の名前・ID、ローカル最新版のサイズと仕様、アップロード結果と取得後のファイル名・サイズ・閲覧URLを確認して制作記録へ残す。ローカルハッシュしかないときにDrive側のハッシュ一致まで確認済みと書かない。別案件のフォルダIDへ送らない。元素材・患者画像・案件の制作記録は依頼なく共通ライブラリや公開サイトへ載せない。
