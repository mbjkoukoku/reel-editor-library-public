# 写真・画質・部分差し替え

素材の受領、写真を使う短い紹介、画質調整、完成後の部分修正に使う共通手順。今回のユーザー指定を優先し、完成承認済みの動画へ新方針を一律に遡って適用しない。

## 指定された素材を保持する

写真や一時保存の素材は、読めた段階で案件の作業場所へ原本コピーを保持する。元ファイルを移動・上書きせず、元の場所、コピー先、画像寸法、取り込み後の資産IDを案件メモへ記録する。取り込みが完了したか、実際に表示できるかを別々に確認する。

利用者が指定した原本を優先する。LP等から代替を取得する場合は、同じ店舗・場所であることに加え、赤丸・矢印・文字・画面UI・トリミングの違いを確認する。注釈付きの別版を指定原本と同一だと扱わない。赤丸などが不要という指定なら、注釈なしの支給原本がある場合はその差し替えを優先する。案内に必要な注釈まで一律に削除しない。代替した理由と見た目の違いは短く伝える。

地図などの代替素材で仮対応した後に指定写真が届いた場合も、その原本を優先して該当区間を差し替える。仮対応で使った素材を既定として残さず、後着の写真も同じ保管・取り込み確認を行う。

## 言葉と動作に合う素材選び

追加素材の選定や同じ場面の反復整理は[素材選びの共通手順](shot-selection.md)を使う。字幕・発話と見える動作を対応させ、既使用区間を照合し、指定された指差しや挿入位置を完成画面で確認する。

## 説明に合う写真と控えめな動き

アクセス・外観・内観など、説明に必要な短い場面では今回の店舗写真を使える。話の内容に合う素材を選び、適切な写真がある場合に無関係な施術映像で場所の説明を埋めない。施術や運動の説明は、それが実際に見える映像を優先する。

写真に動きを付ける場合は、必要に応じてゆっくりした横パンなどを使う。先に入口・看板・室内の設備など、その説明で見せたい部分を決める。中央を基準にしたcoverを機械的に採用せず、写真の縦横比から画面を覆う大きさと移動余白を求め、必要な部分が残る位置へ合わせる。開始・中間・終了で黒い縁、過剰な拡大、文字の読みにくさを確認する。写真の枚数・順序・尺・移動量・中心位置は発話と構図に合わせ、特定案件の値を共通固定値にしない。

写真の余白やぼかし背景を減らす依頼では、入口・看板・人物・手元・資料など、説明に必要な部分を先に決め、その部分を残せる範囲で拡大する。必要な部分が収まる写真は画面を埋め、全面表示で必要な部分が切れる写真は最小限の背景を残す。全写真へ同じ倍率や全面表示を強制せず、横移動の全区間と字幕を重ねて構図を確認する。低解像度写真を拡大して残る柔らかさは、細部が復元されたとは説明しない。拡大後も顔の見切れやモザイクの隠し漏れを新しい合成で確認する。

## 自然な補正と費用の範囲

暗さ・ぼやけを指摘されたら、元画像や元動画の解像度と実映像を確認し、プレビューだけの低画質と区別する。現在の接続で使える通常の明るさ・色・鮮明さの調整を確認し、肌や白い壁が不自然にならない範囲で比較する。低解像度素材へ不要な拡大や追加ズームを重ねず、1080pへの書き出しだけで失われた細部が戻るとは説明しない。

クレジットを使わない指定がある場合は、有料の生成・高画質化へ切り替えない。通常の編集操作や、既存写真に動きを付ける手書きのMotion Graphicで対応できる部分を進める。明るさ補正の操作が現在の接続から使えない場合は、その制約と実行できた範囲を伝える。補正依頼だけを有料処理や別のアプリの導入許可と解釈しない。費用と保存経路は[local-delivery.md](local-delivery.md)を参照する。

## 視線・姿勢・動きから採用区間を選ぶ

施術・実演の映像は、説明に必要な動作と視線が自然につながる区間を選ぶ。意図しない顔上げ、よそ見、ポケットに手を入れる動作、構え直しなどが説明の妨げになる場合は、同じ素材内の自然な区間か適切な別素材へ切り替える。カメラに話しかける場面の目線まで一律に除外しない。

映像の採用範囲だけを直すときは、元映像の時刻と完成タイムラインの時刻を分け、fps・再生速度・トリミングを確認する。同じ長さと速度を保てる範囲を優先し、手の位置・身体の向き・画角・動作が前後で自然につながるか見る。同じ原本の連続する箇所は活用できるが、連続性のために不適切な動作を残さない。本人発話を映像と一緒に使う場合は、口の動きと声の同期も保つ。別ナレーションを使う施術映像と区別し、同期録音の映像だけを別時点へずらさない。元の発話と尺を保てる別画角や手元のカットを選び、適切な候補がなければ不足を伝える。発話そのものを再編集する必要がある場合は、映像・音声を一緒に扱い、映像だけの修正として進めない。尺を保つだけの逆再生・速度変更・静止でごまかさない。

一瞬の顔上げなどを修正する場合は開始・中間・終了の代表画像だけで完了にせず、変更区間を連続して確認する。疑わしい瞬間とカット前後はフレーム単位で調べ、修正版MP4でも変更区間と前後を見る。顔が画角外になった部分は、見えない視線まで確認済みと扱わない。

## モザイクだけの部分修正

[顔モザイクの共通手順](face-mosaic.md)で患者の顔が映る区間を調べ、効果だけを追加・修正する。映像の採用範囲・音声・字幕・尺を保持し、目・鼻・口・頬が一瞬だけ出る境界も確認する。保存値と合成画面が違う場合は、下記のプレビュー同期確認を行ってから範囲を調整する。

## 効果音だけの部分修正

[効果音の選定・調整](sound-effects.md)に従い、指定された音だけを変更する。音量・音色・余韻のどれが不満なのかを今回の指示から読み取り、前の修正で決まった小さめの音量なども引き継ぐ。指定外の声・BGM・他の効果音・字幕・映像・尺を保ち、元の音が二重に残っていないか確認する。

## 音声の差し替えと字幕時刻の修正

支給音声を差し替える依頼は[完成後の音声差し替え](provided-narration.md#完成後の音声差し替え)に従う。今回指定された原本を内容まで照合し、文言が同じなら承認済みの字幕デザインを保って発話ごとの時刻を合わせる。映像・モザイクは必要な変更がない限り保持し、発話や文字の動きに同期する独立した効果音だけを必要に応じて再同期する。

## BGMを残して声だけを部分修正する

[BGMを保って声の一部だけを修正する手順](audio-partial-repair.md)に従う。今回の元編集データから別の声・BGMを確認できれば、BGMの位置・音量・連続性を保ち、声だけを修正する。語中の間と語尾・語頭、元ミックスへ戻る境界、修正版MP4を確認する。文字だけの修正や全音声なしの指定へ適用しない。

## 部分差し替えの確認

写真や一部の映像だけを修正する場合は、対象区間の開始・終了、基準音声、字幕の文言・時刻・スタイルを保つ。写真の縦横比が変われば、表示位置と移動余白は新しい素材で合わせ直す。対象区間の前後、動きの途中、文字との重なりを合成画面で確認し、隣のカットや音声にずれがないか見る。

プレビューに旧素材や旧スタイルが残る場合は、対象のプロジェクト・タイムライン・資産・項目IDと、保存された新版の内容を照合する。保存内容が正しければ、表示が古いことだけを理由に資産を重複作成したり同じ保存を繰り返したりしない。必要に応じて編集画面を再読み込みして同期を確認し、更新後の表示を見るまで見た目を検証済みとしない。

部分修正ごとに版を区別し、保存成功、合成表示の確認、MP4の書き出し、実ファイルの確認、音声込みの全編再生を別々に記録する。新版の比較なしに旧版の確認結果を引き継がない。音声修正で不変の映像・モザイクを再利用する場合は[全フレーム比較の条件](provided-narration.md#修正版の確認と保存)に従い、今回の比較を根拠にする。修正版MP4では該当箇所が新しい素材になったことを確認し、確認した版とファイルを対応させる。未実施の全編再生・試聴は、静止画確認やファイル検査だけで完了扱いにしない。

変更前後の項目を比較し、指定箇所以外が保たれた根拠を記録する。映像だけの変更なら全音声の保持も確かめる。同じ出力経路で音声ストリームが一致すれば有効な証拠になるが、別の再エンコードでバイト一致を必須にせず、素材・区間・ゲイン・フェードと出力音声を照合する。短い修正では前後の文脈を含むプレビューも用意すると、利用者が変更点を確認しやすい。

ユーザーの完成承認は、エージェントによる合成確認・書き出し・試聴とは独立して記録する。ユーザーが完成として作業終了を望む場合は、その意向を尊重し、未検証の範囲を分けて伝える。完成承認を根拠に未実施の確認を完了へ変更しない。
