A03は[音声なしの手順](caption-only.md)を優先する。施術中の会話と訴求テロップは別であり、縦書き主体の原文の大枠・順番を保つ。地域や料金などはLPと照合して先にテロップ台本で確認し、素材動画だけを受け取る。読み上げ原稿・音声・BGMは不要。

A04はLP・読み上げ台本・AI音声の準備が不要。今回の素材で話した内容をそのまま字幕化し、見本からはデザインと効果音の役割を引き継ぐ。見本の原稿や尺を流用しない。

A05は[a05.md](a05.md)を優先する。LPから短い画面テロップ・院名・配色案だけを作り、確認後に対応する施術前後の素材を受け取る。AI音声は求めない。前後は素材の説明や記録で確認し、見た目から推定しない。動作時間を保持し、顔のモザイクは移動・反射・画面変形後も確認する。見本の院名・結果・約47.8秒は流用しない。

A06（A6）は[a06.md](a06.md)を優先する。依頼文と元音声付き素材を最初に受け取り、内部で時刻付き発話を分析して短いテーマ・要点を選び、コーラル帯などの見本デザインへ配置する。LPは店舗情報・予約先の確認用で任意。読み上げ台本・AI音声は不要で、逐語字幕を付けず元声を保持する。見本の文章・店舗情報・成果は流用せず、要約を本人の直接引用とは扱わない。新規AI音声・BGM・効果音は既定で追加しない。顔モザイクは共通手順を使う。

A07（A7）は[a07.md](a07.md)と[0.10.5の完成承認版](a07-approved-profile.md)を優先する。本文78px／行送り104px、時計75px／100px、締め90px／118pxと同梱OFL書体・描画資産を使う。静かめのBGM、起床アラーム等の効果音、昼12時の院調べ、帰宅・いつもの家事→腰が軽い／家事が楽という感情→旅行への意欲→来てよかった、の架空ストーリーを台本で確認する。AI生成・サンプルの常時隅表示は既定で空。患者役素材は必須提出させずこちらで計画し、1本内同じ人物・別動画は別人物にする。生成前に動作の開始と終了・素材再利用・本数・秒数・費用を具体化し、許可範囲内だけ実行する。確認済み院情報と架空人物の物語を分け、実患者の効果証明へ流用しない。原音の使用は現在の許可を確認し、音源の第三者再配布や包括利用は保証しない。ネイティブ合成・ローカルMP4・完成承認1件を確認済み、他利用者の一連の実行は未検証。

A08（A8）は[a08.md](a08.md)の `promo_then_original_speech` を優先する。LPまたは確認済み店舗情報で前半の画面テロップ台本と後半の撮影用案内文を確認し、その後に施術・検査と本人の呼びかけの元音声付き素材を受け取る。素材受領済みなら後半は今回の実発話が根拠で、承認済み内容の再確認は不要。新規AI音声は求めない。前半のNoto Serif JP Black 900＋半透明グレー角丸帯、後半のCorporate Logo Rounded ver3 Bold 700＋白い小字幕・赤強調を使い、OFLの2書体を同梱する。元の7カット・12テロップ・約27.23秒は固定せず、カットと字幕を独立させる。元編集データにアニメーション・キーフレーム・トランジションの設定はない。原画面1080×2336を勝手に16:9へ切り抜かず、出力比率に合わせて座標を確認する。全ミュート・全編逐語・患者役生成へ振り分けず、本人声、顔モザイク、全文の合成と最後の映像・音を確認する。元見本の地域・割引・効果や許諾未確認の音源を流用しない。登録だけならLP不要。原見本分析・登録と、新素材のChatCut編集・MP4確認は別で、後者は未検証。

共通ライブラリの案内版は0.10.7。支給音声の差し替えと字幕再同期は[専用手順](provided-narration.md#完成後の音声差し替え)を使う。A06は新素材1件の完成承認から、Noto Sans JP 900相当の近似字体、非負の字間、2行の行高1.15〜1.22、小さい文面とカード余白の調整、大きな1枚での本文・終盤確認を制作既定へ追加した。元見本の書体と同一とは扱わない。効果音を使う案件は[sound-effects.md](sound-effects.md)、視線・動作の採用区間や部分修正は[media-revisions.md](media-revisions.md)を参照する。本人発話・支給ナレーションの字幕編集は[speech-cleanup.md](speech-cleanup.md)で、明らかな言い直し・重複、語頭語尾、適用後の再監査まで確認する。新規編集で実在の患者の顔が映る場合は[顔モザイクの共通手順](face-mosaic.md)を使う。A01〜A03の新規台本は[原見本の文章](reference-script.md)を土台にし、院名・地域・駅名など必要な事実だけを差し替える。A01/A02の「まず台本だけ」の依頼ではLPから読み上げ台本とテロップ・仮の映像案を作り、素材と音声は台本確認後に同じタスクで受け取る。[台本作成の手順](script-first.md)を使い、映像編集とは段階を分ける。A01は0.4.4で1案件の完成承認とテロップ修正を反映し、[初回完成度を上げる手順](a01-approved-workflow.md)と元フォントの本文描画値を既定へ追加した。原見本の観測はa01-reference.jsonに保持する。A02は2026-10-06に完成承認されたブラッシュアップ版を既定とする。素材、店舗情報、出力先は案件ごとに変わる。見本の店名・価格・効果の表現は新店舗の文章へ自動流用しない。

いずれも完成尺は素材・文章・発話に合わせる。AI音声は既定で追加しない。BGMはA07とA08の専用方針を優先し、それ以外は既定で追加しない。本人の発話モードでは元声を保持する。同じプラグインに今後のパターンも追加し、サイトで選んだ番号を依頼に含める。

A08は前半の院紹介と後半の今回の本人声を組み、専用手順を保つ。A07は画面台本・時刻・患者役の連続性と完成承認版を基準にし、許可された音源の静かめBGMと効果音を入れる。新規AI音声は追加しない。A05の元音声は今回の指定に合わせて扱い、音声なしの指定があればミュートする。音声の有無だけでA03へ変更しない。A03や明示された音声なしの依頼は音声を使用しない。A06は元声の分析と要点デザインを優先し、別音声が渡された場合も逐語字幕へ自動で切り替えない。それ以外で今回使用するAI音声・ナレーション入り動画が提供された場合は、選択したデザインを保ち、音声の内容・時刻と指定番号を参考に映像を配置する。AI音声の新規生成は行わない。詳細は[支給ナレーションと番号付き素材](provided-narration.md)を読む。
