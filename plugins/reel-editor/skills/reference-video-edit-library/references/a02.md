# A02｜承認済みの院紹介・太字と色付き強調

今後のA02制作は、2026-10-06に利用者が完成として承認したブラッシュアップ版を既定にする。[a02.json](a02.json)の`productionProfile`、`typography`、`cues`が適用値。[描画・読みやすさの手順](a02-rendering.md)も読む。主見本「院紹介動画.mov」の分析は[a02-reference.json](a02-reference.json)へ残すが、その古い位置・色・発光で承認版を上書きしない。現在のユーザー指示が最優先。

入力は今回の素材と店舗LP、または利用者が直接確認した店舗情報。以前の店舗名・駅名・価格・素材ID・ファイルパスを持ち越さない。承認版の設定は同梱しており、過去の案件や特定のChatCutプロジェクトへアクセスできることを前提にしない。

## 台本

新規台本は[参考台本への寄せ方](reference-script.md)と[A02の画面テロップ原文](a02-script-reference.json)を使う。原見本の言い回し・順番・短い問いかけを保ち、今回の店舗情報を必要な箇所に差し替える。原見本の本文を使うことと、0.4.2で改善した配置・読みやすさを元へ戻すことは別である。承認済み台本・支給音声は優先する。

## 配置と文字

- 原則1〜2行、最大2行。長い文章は意味と発話の境界で複数の字幕へ分け、店名や単語を省略しない。
- 1080×1920では静止後の字面中心をX=540、Y=1140（横50%、縦59.375%）へ揃える。アニメーション用の外側の枠ではなく、実際の文字の中心を合わせる。
- 行幅の基準は960px、行送りは1.15em。大小を混ぜた明朝は実字形の上下を測り、行の間に0.12em程度の空きを確保する。拡大・縁・影・斜体も含め画面に収まるか確認する。
- 本文は白い太字ゴシック＋暗い縁＋黒い影。導入・強調・案内はそれぞれの色、大小、明朝、アニメーションを保ち、全編同じ字体・色へ統一しない。
- 肌や床の上でも読めることを優先する。テーマカラーだけを一括で文字へ適用しない。読みづらい金色文字を、淡い黄色＋淡色の縁＋白い発光へ戻さない。

## 場面の役割とスタイルを対応させる

`a02.json`の`cues[].key / role / style`を対応の正本にする。配置前に、今回の各字幕へ「参照cueキー・今回の文言・採用スタイル・差分があれば理由」を記録する。字幕番号や文章の印象だけで色を選ばず、アクセス、相談、検査、施術方針、セルフケア、案内などの役割を照合する。

音声に合わせて1つの役割を複数字幕へ分けた場合は、各字幕に同じ参照cueとスタイルを引き継ぐ。短い区間の動きは読む時間に合わせて調整できる。役割が変わるところだけ対応を切り替える。今回の文言・軽いオファーを、役割を合わせるために見本の価格や主張へ書き戻さない。見本に対応しない内容は近い役割と選択理由を記録する。

静止後の全字幕を原見本の対応場面と比較し、スタイルの数値だけでなく「その場面にそのデザインを使っているか」を確認してから入場中の比較へ進む。支給音声の順番・発話時刻は優先し、原見本の字幕数や尺を強制しない。

完成後の音声差し替えは[専用手順](provided-narration.md#完成後の音声差し替え)を使う。言葉が同じなら参照cue・役割・字体・色・改行・静止位置を保ち、新しい発話ごとに字幕時刻を合わせる。対応する文字の入場・着地へ同期した効果音も必要に応じて合わせ直す。音声の変更だけを理由に全字幕を同じデザインへ作り直さない。

BGMを残して声の一部だけを直す場合は[BGMを保って声の一部だけを修正する手順](audio-partial-repair.md)を使う。元の別素材を照合し、BGMは連続、声は語尾・語頭を保って局所修正する。原見本や0.4.2の文字デザインを音声修正だけで変えない。

## カットと尺

原見本の基準は14場面・約53.33秒の映像部分。末尾の黒い13フレーム（約0.43秒）は含めない。悩みの人物→短い場所紹介→相談・検査・施術→特徴→案内という役割を使い、人物と実際の施術が見える映像を優先する。

支給ナレーションがある場合は、話の内容・順番・長さに映像とテロップを合わせる。原見本の14場面・22字幕、0.4.2の承認事例の43.93秒・25字幕へ固定しない。[フィラー・長い間の整理](speech-cleanup.md)を先に行い、整理後の音声を基準にする。意味のある言葉の途中切り・速度変更・内容の削除・二重再生をしない。映像側の素材音は既定でミュートする。AI音声・BGMの新規追加は不要。

無人の外観・内観は必要な紹介に限る。過去の店舗の映像や無関係な映像で尺を埋めない。今回の素材に不足がある場合はその範囲を伝える。明るさは肌の色を保つ軽い調整だけを基本にする。

### 説明・動作と場面の反復

[素材選びの共通手順](shot-selection.md)に従い、相談・検査・施術・セルフケア・予約案内を実際の動作で区別する。追加素材を既使用区間と照合し、内容に合う未使用の場面を優先する。「下のリンク」の指差しは方向・発話時刻・指先の見え方を合わせ、指定された素材の移動先も守る。文の区切りと動作に合わせて切り替え、全カットの秒数や別素材の数を固定しない。A02の役割別文字デザインと指定外の音声・字幕・尺は保つ。

セルフケアの実演が不足していても、今回の指示で説明映像が認められる場合は、資料を使い患者へ伝える動画区間を説明として選べる。前後の施術や近接する相談場面と比較し、未使用区間・適切な寄りで見え方を変える。実演との区別、同じソースの反復確認は上記の共通手順に従う。

### アクセス案内に使う写真・映像

駅名・徒歩時間の区間は、確認済みの当該駅や実店舗の外観・内観など、場所が伝わる画を選ぶ。同じ院の素材でも、入室や施術の映像がアクセス説明に適切かは別に判断する。適切な動画がなく写真がある場合は、[素材の保管と部分修正](media-revisions.md)に従って指定写真を優先する。LPの別版に丸印・矢印・文字がある場合は同一の原本と扱わない。

写真に動きを付ける場合は控えめな水平移動を使える。枚数・秒数・移動量を過去の事例に固定せず、発話時間と構図に合わせる。駅写真や外観・内観の両方を必須にせず、駅を確認できなければ実店舗の写真でも場所紹介を伝えられるか判断する。全体の施術映像を静止画へ置き換える方針ではない。[写真の描画確認](a02-rendering.md#写真を横へ動かす場面)を使い、既存のアクセス用文字デザインと最大2行・中央やや下の配置を保つ。

写真の余白を減らす場合は[写真拡大の共通手順](media-revisions.md#説明に合う写真と控えめな動き)を使う。入口・看板や説明に必要な人物・資料を残せる範囲で拡大し、全面表示で切れる場合だけ必要な背景を残す。

## 効果音の役割と使い分け

音声ありのA02では、意味の山場を選んで短い効果音を加える。今回の音源・音量・音を付けない指定を最優先にし、既に支給音声にある効果音は二重にしない。次の表は0.7.3の承認済み実制作から得た選定候補で、原見本の全音源を同定した記録ではない。文言や字幕番号が違っても意味と動きで役割を選ぶ。

| 場面の役割 | 候補と選び方 |
|---|---|
| 強い注意喚起・警告 | 短いインパクト音。迫力のある文字の出現・着地に合わせる |
| 新しい着眼点・原因の可能性 | 短いクリック音など。今回の実制作ではパソコンのクリック音が指定された |
| 悩みの反復・落胆 | 低く余韻のある「ガーン／ガ〜ン」。余韻の長さを文の区切りへ合わせる |
| 相談への誘導・軽い切り替え | 必要なら軽いポップ音。音が不要な箇所は付けない |
| 院名・最後の案内 | 短い「キラーン」など明るい締め。前の説明へ連発しない |

同じ音が続かないよう前後を確認するが、音の種類を増やすこと自体を目的にしない。全字幕へ機械的に付けず、明るい音を落胆の説明へ当てるなど意味のずれを避ける。支給ナレーションとBGMがある場合も、言葉を妨げず効果が聞き取れる音量へ調整する。音源を替えたら元のdB値を流用せず、以前の音量希望も引き継ぐ。音色・余韻・主音の位置・音量・試聴の具体手順は[sound-effects.md](sound-effects.md)を使う。

## 冒頭の動きとカットのつなぎ

冒頭に施術・実演を見せる場合は、施術箇所へ自然に注意を向けている区間を選び、一瞬の顔上げや構え直しも確認する。手元への寄り画につなぐ場合は動作の流れを見て採用範囲を決める。映像だけの修正では注意喚起テロップ・音声・効果音・区間尺を保つ。確認方法は[採用区間と部分修正](media-revisions.md)を使う。カメラに説明する場面の目線まで禁止するものではない。本人がその場で話す映像は口と声の同期を優先し、別時点の顔の映像だけを元声へ重ねない。

## 患者の顔モザイク

顔が映る区間には[顔モザイクの共通手順](face-mosaic.md)を適用する。問診の画面端の頬や、検査・姿勢指導中の横顔も確認する。固定範囲で全動作を覆えるかを確認し、必要なら位置・大きさを追従させる。中央やや下の字幕や施術者の手元を不必要に覆わない。部分修正では支給音声・字幕・区間時刻を保つ。
