# 効果音の選定・調整・部分修正

## 適用する場合

音声を使う編集で、今回のユーザーが効果音を求めた場合、または選択したパターンが効果音を標準に含む場合に使う。台本だけの段階では実行せず、A03などの無音指定へ効果音を自動追加しない。今回の明示指示を最優先する。

A02では、承認された実制作から得た「場面の役割に合う少数の効果音」を標準候補にする。A02固有の役割は[a02.md](a02.md)を参照し、全字幕への自動付与や、過去の音源・配置数・時刻の固定はしない。この方針をA01など他パターンへ自動で広げない。A04は[a04.md](a04.md)の強調音・締め音の条件を保つ。

「効果音なし」「この音だけ」「小さめ」などの指定と、承認済みの音を優先する。BGMの新規追加、支給音声に含まれるBGM、追加する効果音は分けて扱う。支給済みのナレーション・BGMを勝手に除去・重複させない。

## 場面の意味に合う音を選ぶ

1. 発言の意味、字幕の役割、映像の動きから、その音を鳴らす目的を決める。注意喚起、気づき、落胆、相談、締めを区別する。
2. 「PCのクリック」「落胆するガーン」「キラーン」など、今回の指定がある場合はその種類を優先する。別ジャンルへ独断で置き換えない。
3. 正規に利用できる元音源・支給素材・既存ライブラリを確認する。名前だけで音の性質を断定せず、短い文脈の中で適合を確かめる。
4. 同じ音の不要な連続や、毎回同じ強調音になる構成を避ける。同じ役割で意図的に繰り返す場合はよい。種類を増やすためだけの音や、全テロップへの音付けはしない。

原見本と同じ音源だと確認できた場合と、別の広告テンプレ由来の音・無料の類似音を区別する。似た名称や印象だけで「原見本と同一」と扱わない。

## 音色・余韻・音量を分けて直す

「聞こえない」は、音量不足だけでなく、発話・BGMとの重なりや音色の問題も確認する。「合わない」は音源の性質、「長く響かせたい」は減衰と採用範囲、「少し大きい」は対象音の音量を中心に調整する。一つの不満に対して無関係な項目まで変更しない。

音量は実際のナレーション・BGMと合わせ、効果音が認識でき、言葉が明瞭に聞こえる範囲へ調整する。「控えめ」を、ほとんど聞こえない設定のまま済ませない。素材ごとの元音量や周波数が違うため、同じdB値を一律に当てはめない。

「少し下げる」場合は指定された音だけを小幅に下げ、音源・開始・長さ・他の音を保つ。元音源を変更する場合も、直前の「小さめ」「これ以上大きくしない」という希望を引き継ぐ。音源が変われば調整値そのものではなく、前版との聞こえ方や実測レベルを比較する。

余韻を伸ばす前に、後半に実際の音が残っているか確認する。ほぼ無音になった末尾の延長だけでは、音色や持続感は変わらない。必要なら同じ意図の別音源を選び、次の発話・場面を邪魔しない範囲に収める。既に承認された音まで一度に選び直さない。

## 主音を発話・文字の動きへ合わせる

- ファイルの先頭、頭の無音、音の立ち上がり、強い部分を分けて確認する。ファイルを字幕開始へ置いただけで同期したと判断しない。
- 強調する言葉や、文字の出現・着地など、今回の目的に主音を合わせる。少し先行させる場合も、場面より早く鳴りすぎないか確認する。
- sourceIn、完成側の開始と主音の位置、使用尺、音量、フェードを別々に記録する。波形の立ち上がり・短時間RMS・ピークは主音候補を測る補助に使い、最大ピークだけで聴感上の主音を確定しない。単位とフレームレートは現在のツールで確認し、別案件の数値を流用しない。
- 不自然な末尾切断を避け、必要なら短いフェードを付ける。長い余韻は次の役割にかぶりすぎないよう確認する。音に合わせるために支給発話や映像の尺を無断で変えない。
- 発話整理やカット変更で時刻が変わった場合は、効果音も新しい完成時刻へ合わせ直す。

## 編集可能な状態を保ち、変更した範囲を確認する

追加する効果音はナレーション・BGM・映像と分け、ChatCutで音源・開始・範囲・音量を後から直せる状態にする。一本へ焼き込んだ動画だけを編集可能な成果の代わりにしない。

部分修正では対象音だけを更新し、指定外の映像・字幕・元音声・全体尺・他の効果音を保つ。差し替え前の音が重なって残らないことを確認する。保存値を読み直し、修正版MP4でも変更が反映されたか確かめる。

音の比較が必要な場合は、該当箇所の前後の発話と映像を含む短い確認用MP4を、現在利用できるChatCutの書き出し経路で用意する。音源単体だけの確認で済ませず、長すぎる全編の確認を毎回求めない。短い確認用MP4と完成版MP4は区別する。

検証は変更に合わせる。音量だけなら同じ音の音量差・同期・区間外の維持、音源変更なら新音の反映・旧音の除去・開始と終端・発話との重なりも確認する。問題がなければ、変更していない全効果音の試験を理由なく繰り返さない。

## 実聴と数値検査を区別する

実際に聞ける場合は、発話の聞き取りやすさ、音色の意味、余韻、主音の位置、切れ方を確認する。直接聴取できない場合はその範囲を明記し、音源名や波形だけで「自然に聞こえる」「音色が合っている」と断定しない。ユーザーの完成承認は、エージェントの実聴・全編再生の記録とは分ける。

数値では、対象音の波形・同期・ゲイン・クリッピング、元音声と区間外の維持などを確認できる。音源を替える際はピークだけでなく短時間の強さや持続も比較する。ただし、数値が同等でも主観的な大きさや聞き取りやすさが同じとは限らない。

配置前のミックス推定と、実際に書き出した音声の検査は分ける。出力では、基準音声との時間対応を合わせたうえで既知の効果音の波形・差分・相関を使い、予定位置とゲインでの反映、追加音の区間外の維持、サンプルクリッピングを確認できる。フェード形状・再サンプリング・圧縮による差を記録し、完全一致を前提にしない。RMSをLUFS、サンプルピークをtrue peakと呼ばず、測定値や閾値を次の素材の固定基準にしない。

圧縮音源のデコードやsourceInの解釈による微差が疑われる場合は、実際の差を調べて記録する。波形不一致を無説明で合格にせず、測定した差と映像・発話への影響を分ける。特定の案件で得た差を、次の素材への補正値や許容値に固定しない。

保存成功、設定の再確認、合成表示、修正版MP4の検査、部分試聴、音声込みの全編再生を別々に記録する。確認した版とファイルを対応させ、旧版の結果を新しい版の確認済みとして引き継がない。[部分修正](media-revisions.md)と[保存・無料範囲](local-delivery.md)も参照する。

## 素材の入手と共有

費用なしの指定では、利用可能な既存素材や無料で使える音源を確認し、有料生成・有料素材へ無断で切り替えない。適合する音が入手できなければ未追加と伝え、他の編集は進める。

取り込みに失敗した音源は、拡張子だけで形式を判断せず、実コンテナ・コーデックと現在の取り込み機能の対応形式を確認する。例えばMP3の名前でも実体がAAC/M4Aの場合がある。必要なら原本を保持したまま対応するPCM WAVなどの作業用複製を作り、尺・チャンネル・主音の位置・レベルの変化を照合して実際に取り込めることを確かめる。拡張子の変更だけで修復済みにせず、形式変換のために意図しない音量・音色・タイミング変更を加えない。

音源名、提供元、確認した利用条件、採用範囲を案件に記録する。完成動画への組込みができることと、音源本体を再配布できることは区別する。共有動画編集ライブラリには手順と必要な出典情報を保存し、第三者の効果音本体、個人キャッシュ、私的な素材パスや案件IDを配布しない。各利用者が正規に取得できる範囲で運用する。
