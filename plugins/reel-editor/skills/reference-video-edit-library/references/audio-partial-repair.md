# BGMを保って声の一部だけを修正する

「名前の末尾の一音だけを取る」「BGMはそのまま、言い間違いだけを直す」など、利用者が指定した小範囲の音声修正に使う。一般のフィラー整理を全編へ追加適用する手順ではない。表示上の院名や字幕まで変更する指示と混同せず、指定外の映像・字幕・効果音・モザイク・尺は必要がなければ保つ。

## 先に元の声とBGMを探す

- 完成MP4の声とBGMが混ざっていても、直ちに分離処理や再提出を前提にしない。今回の提供素材と、アクセス可能な当該案件の元編集データを先に確認する。CapCut等の元プロジェクトが別のナレーション素材・BGMを参照していれば、その参照先を読み取り、同じ版か確認する。無関係な案件の探索や元プロジェクトの書き換えへ広げない。
- 見つけた原本を案件内へコピーし、取得元・内容ハッシュ・音声ストリーム・元編集での配置、使用範囲、速度、ゲイン、フェードを残す。拡張子だけで内部形式を判断しない。変換が必要なら原本も保持する。
- 別素材と完成MP4の音を照合する。エンコードによる開始遅延やサンプルレートの違いを含め、今回の実測で時間対応を求める。声が強い箇所の相関だけでBGMも同じ位置と決めず、声のない箇所などでBGMの位置・音量を独立して確認する。特定案件の遅延・音量・秒数を既定値にしない。

## BGMを連続させ、声だけを編集する

元の別素材が確認できたら、必要な修正区間を独立した声とBGMのトラックで組む。BGMは元と同じ再生位置・速度・音量で連続させ、声のカットに合わせて詰めたり、無関係な文間のBGMを繰り返して埋めたりしない。同じ区間の元ミックスは外し、声やBGMが二重に鳴らないようにする。変更区間の外側まで全編の音を作り直す必要はない。

削除する音と、その前後に残す語尾・語頭を別々に確認する。ASRが複数の文字や音を一つの単語として返した場合、単語全体の削除で代用しない。通常の語句削除は現在の発話編集手順を使い、単語内の指定音だけの修正では原音・波形・必要に応じたスペクトルを根拠に、利用できる細かいカット操作へ進む。ASRの訂正で存在しない音素時刻を作らない。

語中の音を消した長さだけ空白に置き換えると、名前の途中に不自然な間が残る。残す言葉が自然につながるよう声を詰める。全体尺を保つ必要がある場合は、前後の文間で無理なく調整できるか確認し、次の発話・字幕の同期を保つ。文間を不自然に長くして帳尻を合わせず、局所的に保てなければ必要な同期変更を明確にする。本人の口が見える映像では口と声の同期を優先し、声だけをずらさない。

接続点は、語尾や次の助詞の出だしが欠けず、振幅の段差も小さい位置を選ぶ。近傍のゼロクロスや位相の調整はクリック抑制の補助であり、正しい音の境界や自然さの証明ではない。短い語へ一律の端フェードを付けると、1フレームでも語頭・語尾が弱くなることがある。使える時間単位と丸めを確認し、必要な場合だけ音を傷めない長さで処理する。元の混合音声へ戻す境界でも、BGMの位置・音量と声の重複・欠落を確認する。

## 別素材が見つからない場合

混合音声を丸ごと切ればBGMの時間も変わり、ミュートすればBGMも消える。これを「声だけの修正」「BGMをそのまま保持」と説明しない。今回の接続で使える分離機能がある場合は、費用・利用条件と実際の分離結果を確認する。声だけを強めるVoice Isolationや左右差分は、元BGMの完全な復元を保証しない。分離による音質変化や残留声があれば、その範囲を明示する。

元素材の確認と可能な局所処理を進めても希望する保持が難しい場合に限り、声のみ・BGMのみの元素材など、足りないものを具体的に案内する。提供済み音声を再提出させたり、無断で新しい声・曲を生成したりしない。クレジットを使わない指定では有料の分離・生成へ切り替えない。

## 修正版を確認して渡す

編集可能な声・BGMの区間と素材対応を保存し、別名のローカルMP4を書き出す。変更前後の一文を含めて、次を確認する。

- 指定した音だけがなくなり、残す院名・語尾・助詞・次の言葉が保たれているか。ASRは補助にし、波形や認識文だけで自然な聞こえ方まで確認済みにしない。
- BGMが元の位置・音量で連続し、ループ、欠落、二重再生、拍のずれ、音量の急変がないか。書き出した実音声と元素材を照合し、声とは別の根拠で確かめる。
- 接続点のクリック、急な無音、語頭・語尾の減衰、クリッピングがないか。変更区間外の音声、字幕・効果音・口の同期が保たれたか。
- 映像を保った場合は[修正版の全フレーム比較](provided-narration.md#修正版の確認と保存)で映像・モザイクの保持を確認する。再圧縮による微小差と実内容の変更を分ける。

前後の文脈を含む短い確認用動画と全編MP4を渡すと、変更点を確かめやすい。確認用動画も全編の対応区間と一致するか調べる。区間・版・ファイルに対して、数値検査、ASR、直接試聴、音声込み全編再生、利用者の完成承認を別々に記録する。直接試聴できないときは未確認として伝え、試聴済みや違和感なしと断定しない。
