# 参考動画の文章を土台に台本を作る

A07（A7）は[a07.md](a07.md)を優先する。LPまたは確認済み店舗情報から、画面テロップ台本と「利用者が送る施術者・院内映像／こちらで調達・生成する患者役映像」を分けた場面表を作り、確認を待つ。患者素材・読み上げ原稿・AI音声の提出を必須にしない。見本の時刻と日常→来院の構成を参考にするが、実体験・改善結果・院名を新しい事実として流用しない。患者役は1本内で同一人物、別の作品では別人物を使う。AI場面は「イメージ映像（AI生成）」として表示し、生成の本数・秒数・モデル・費用が既存の許可を超える場合だけ実行前に確認する。見本登録だけの依頼では新しい生成・編集へ進まない。以下の読み上げ台本・AI音声準備の案内は適用しない。

A06（A6）は[a06.md](a06.md)を優先する。元音声付き素材の発話を内部で分析して、短いテーマ・要点を見本のコーラル帯などのデザイン枠へ配置する。逐語字幕・LPからの新規読み上げ台本・AI音声は作らない。LPは任意の店舗情報・予約先の確認資料であり、発話分析の前提にしない。見本の文言や成果を今回の発言・事実として流用せず、要約を直接引用とは扱わない。通常は素材受領後に編集へ進み、明示的に「まず案だけ・編集はまだ」と頼まれたときだけ、実発話に基づく画面文案と根拠時刻を出して止まる。以下の台本確認・AI音声準備の案内は適用しない。

A05は[a05.md](a05.md)を優先する。LPから院名・配色と短い画面テロップ案だけを提示して確認を待ち、確認後に施術前後の対応が分かる素材動画を受け取る。読み上げ台本・AI音声は求めず、参考の院名・改善表現・感想を新店舗の事実にしない。前後の判別と結果の説明は素材受領後に確認し、動きの時刻や改善度を先に作らない。最後は「画面テロップと院名・配色をご確認ください。内容が決まったら、施術前と施術後が分かる素材動画をこの同じタスクへ送ってください」と案内する。見本登録だけの依頼ではLPなしで登録し、新店舗用の台本や編集へ進まない。以下のA03・読み上げ原稿の手順よりこの分岐を優先する。

A04は[a04.md](a04.md)を優先し、今回の素材の実発話から始める。LP・新規読み上げ台本を前提にせず、見本の原文へ発言を置き換えない。明示的にテロップ案だけを求められた場合は、実際の発話から案を出して編集前に止まる。

「見本の構成を再現」で新しく台本を作る場合の既定。A01/A02の構成だけでなく、原見本の言い回し、問いかけ、短い文のつなぎ、話の順番、締め方にもできるだけ寄せる。LPは差し替える店舗情報の確認に使い、LPの情報量に引っ張られて別の説明文へ全面的に書き直さない。

## 参照する文章

- A01: [原見本の画面テロップ](a01-script-reference.json)
- A02: [原見本の画面テロップ](a02-script-reference.json)
- A03: [縦書き・横書きの画面テロップ](a03-script-reference.json)。[音声なしの手順](caption-only.md)を使い、施術中の会話の文字起こしや読み上げ台本に変換しない。

これらは原見本の画面から確認した文章の資料であり、原音を直接聴取した逐語録ではない。画面で同時に強調される語、バッジ、価格表示は独立した情報として扱い、読み上げで重複させない。原文の改行と時刻は見本の記録であり、新作を同じ行数・固定尺にする指定ではない。A02は語順を保って字幕を分割し、承認済みの最大2行へ収める。原文の店名・地名・価格・効果は見本の事実であり、新店舗で採用してよい既定値ではない。文字デザインは引き続き各パターンの承認済み制作仕様を使う。

## 保持する部分と差し替える部分

1. 原見本の文章を順に置き、冒頭の呼びかけ、紹介の問いかけ、接続、語尾、オファーまでの流れを保つ。意味が通る限り、固有名詞以外の中立的な言い回しはそのまま使う。読み上げに必要な句読点・助詞・語順の微調整はよい。
2. 院名・地域・駅名・アクセス・対象症状は今回の確認済み情報へ差し替える。院名の読みと画面上の表記はユーザーの指定を守る。
3. 施術内容、資格、効果、実績、感想、料金、保証条件、予約状況、予約導線も店舗ごとの事実として確認する。見本と同じ内容が今回のLPやユーザー提供情報で確認できる場合は、見本の表現を保てる。異なる場合はその句だけを今回の事実へ差し替え、前後の言い回しと位置をできるだけ保つ。根拠がない場合は、その役割に合う確認済みの短い表現へ置換するか省く。
4. LPにあるという理由だけで、資格の長い説明、独自の施術理論、設備紹介などを追加しない。参考動画にない説明を足すのは、今回のユーザー指定か、事実の誤解を避けるために必要な場合に限る。
5. 提示前に原文と今回の文章を対応させ、変更箇所が「店舗情報の差し替え」「事実の差・不足への対応」「ユーザー指定」「読み上げの微調整」のいずれかで説明できるか確認する。文の順序や語り口を大きく変えていたら戻す。参照文を確認できなかった区間は、原文に寄せられたと断定しない。

「固有名詞以外は寄せる」は、他院の効果・実績・価格まで無条件に使う意味ではない。たとえば「○○駅から徒歩○分」「○○という整体院をご存知ですか？」という文型は保ち、中身を確認済み情報へ替える。一方、見本の「初回価格」や改善を断定する表現は、今回の情報に合わせて必要な範囲だけ変える。

## 承認済み台本・音声との優先関係

この既定は新しい台本の初稿に適用する。ユーザーが修正・承認した台本、指定された軽いオファー、確定した店名表記を、見本の原文へ勝手に戻さない。完成承認された動画も、方針更新だけを理由に作り直さない。

A03など音声なしの指定では、素材に音声が含まれていてもナレーションとして採用せず、台本確認後に映像だけを使用する。明示的に音声の使用へ変更された場合に限り、以下を適用する。

支給ナレーションが届いた後は、その言葉・話順・発話時刻を編集の基準にする。参考原稿へ合わせるために音声を切る・速める・作り直すことはしない。台本だけの段階では[script-first.md](script-first.md)の形式で提示して止め、素材やAI音声を先に要求しない。
