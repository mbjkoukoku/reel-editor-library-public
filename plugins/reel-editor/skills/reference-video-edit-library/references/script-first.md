## 今回の入力と範囲

選択されたA01/A02の原見本の文章を土台にし、[参考台本への寄せ方](reference-script.md)を読む。今回のLP・ホームページまたは店舗情報で必要な箇所を差し替え、その他の言い回し・話順・語り口はできるだけ保持する。LPが未提供・読めない場合は、そのURLや必要な情報だけを確認する。素材動画・音声・見本の再添付・ChatCut接続・フォントの用意を、台本作成の前提にしない。ChatCutプロジェクト作成、素材取込、映像編集、AI音声生成、BGM追加はこの段階では行わない。

LPから店名、地域、対象とする悩み、提供サービス、担当者、料金・条件、予約案内を確認する。採用した事実と出典を台本の外に短く記録し、効果・実績・保証・予約混雑を見本から流用しない。情報がない項目は同じ役割の確認済みの短い表現へ置き換えるか省き、原見本の前後の流れを保つ。重要な矛盾だけ確認し、通常の差し替えや読み上げの微調整はCodexが判断して進める。LPにある情報をすべて追加して、原見本から離れた説明中心の台本にしない。

A01/A02の場面の役割、語り口、本文と強調の使い分けを基準にする。承認済みの文言と指定された店名の表示名は保持する。実素材を見ていないため、使うカットや撮影済みの場面が存在すると断定しない。参考動画の固定秒数を完成尺にせず、尺を書くなら読み時間からの概算と明示する。

## 提示するもの

1. **読み上げ用の台本**：そのままコピーしてAI音声の作成に使える本文を、一つのテキストブロックへまとめる。番号、秒数、映像指示、出典、未確認の値を本文へ混ぜない。句読点と自然な読みの順番を整え、テロップで重なる強調語を二重に読み上げない。
2. **テロップと仮の映像案**：順番、読み上げる内容、表示するテロップと改行、合いそうな映像を一つの表へまとめる。「施術者が説明する場面」「施術の手元」などは撮影済みとは限らない仮案と明記する。素材番号や使用開始・終了、発話時刻はまだ割り当てない。文字の見た目は選択したパターンを引き継ぐが、実際の表示確認は編集段階で行う。

読み上げ本文とテロップ表の店名・料金・順序・表現を照合し、原見本から必要以上に言い換えたり、独自の説明を追加していないか確認してから渡す。根拠不足や矛盾で確認が必要な事項は本文の外へまとめる。この段階の成果を「動画完成」「字幕配置済み」と呼ばない。

「話した内容をそのままテロップ化」の方式を選んでいて、まだ発話素材がない場合は、「以下はLPに基づく仮台本・仮テロップ案で、本人の発言の文字起こしではありません」と明示する。実際の発言を作ったように扱わず、発話素材を受け取った後で聞こえる言葉と時刻へ合わせる。既に発話素材があればそれを優先できるが、依頼が台本だけなら映像編集まで始めない。

## 最後に案内する次の手順

台本を提示した最後に、次の案内を付ける。

> 台本をご確認ください。修正があれば、この同じタスクでお知らせください。内容が決まったら、この台本でAI音声を作成し、素材動画とAI音声（音声入り動画でも可）をこの同じタスクへ送ってください。選んだ見本のデザインで、その音声に合わせてカット編集とテロップを入れます。

本人の発話をそのまま使う場合は、AI音声を作る案内の代わりに、本人が話した元動画・音声と編集素材を同じタスクへ送るよう案内する。利用者が音声を使わないと指定している場合も、その指定を優先する。

この台本提示のターンでは次の編集へ自動で進まない。その後、利用者が編集を指示して素材と音声を渡したら、採用された台本を引き継ぎ、[支給ナレーションの手順](provided-narration.md)または元の発話編集へ進む。支給音声の実際の言葉・時刻を確認してから字幕を確定し、仮の映像案は届いた素材の内容に合わせて調整する。台本を作り直す必要がなければ、承認済みの文言や店名を理由なく変更しない。
