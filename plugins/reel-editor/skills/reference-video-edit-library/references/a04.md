# A04：発話テロップ・白い角丸背景

0.6.0で追加した、本人の話を整理して字幕化するパターン。見本は「臀筋 動画.mov」。入力は**今回の話者素材動画だけ**でよい。LPや新しい読み上げ台本を必須にしない。素材がなければ今回の動画を求め、見本の発言で代用しない。

## 発話を整理してから、文字を重ねる

1. 原音と映像を確認し、現在の接続に対応するChatCut基本・発話編集・文字起こしスキルを使う。[speech-cleanup.md](speech-cleanup.md)に従い、日本語の不要なフィラーと長い間、今回指定された明らかな言い直し・重複をScriptで整理する。意味のある返答・ためらい・息継ぎ・意図的な反復は残し、意味・語順・再生速度を変えない。ユーザーの「カットなし」などの指定は優先する。
2. 話者映像と本人の声を一緒に詰める。専門語・固有名詞・文末をASRの単語境界で切り詰めず、自然な言い切りに必要な助動詞・終助詞と短い余韻まで残す。言い直しは完成した1回を残し、失敗した断片だけを削る。
3. Scriptを反映したら同じ範囲を読み直し、完成側の文章、重複、語頭語尾、短い間を再監査する。構造変更後のカットへ短い音声スムージングを適用し、つなぎ目を一文として試聴する。クロスフェードで悪い単語境界をごまかさない。
4. 本人の言葉を要約・言い換えず、意味の切れ目で通常1〜2行に分ける。長すぎる場合は、実際の単語時刻で表示区間を分ける。見本の「いきなりやるのやめてください！」や予約案内を、話していない人の動画へ追加しない。88秒・61区間・元動画のカット数にも固定しない。
5. 映像・元声と独立した、修正できるテロップを配置する。ネイティブ文字と行別の背景、または現在のMGスキルに従うMotion Graphicを使う。本文・強調・効果音を整理後の時刻へ置き、一本に焼き込んだ動画で編集可能な成果を代用しない。字幕refresh後も手動表示に削除前の語が残ることがあるため、完成音声と全カードを照合する。専門語・複合語を改行で分断せず、一文字だけ次行へ残す組み方も避ける。
6. 全てのカット前後を聴き、語頭・語尾・自然な間・口の動き・字幕同期を確認する。尺が変わった場合は強調音・締め音・他レイヤー・末尾を新しい時刻へ合わせ、黒画面や音だけの余りを残さない。本人の声を残し、AI音声・BGMを暗黙に追加しない。

`executionRoute: speech_cleanup_then_overlays`はライブラリ内の分岐名で、ChatCut API名ではない。既存の`timeline_plan.py`・`text_revision.py`はA04の制作経路ではない。固定の見本cueとカットを連動させるhelperへA04を通さず、現在のChatCut Scriptと独立した字幕レイヤーを使う。実在しない対応コマンドは作らない。

## 本文と強調の見た目

[a04.json](a04.json)の`renderTargets`と、同梱の[1行](../assets/a04-reference/body-one-line.jpg)・[2行](../assets/a04-reference/body-two-lines.jpg)・[赤い強調](../assets/a04-reference/emphasis-static.jpg)を比較に使う。見本画像は今回の完成動画へ挿入しない。

本文はヒラギノ角ゴシックW6の黒文字、下中央。**行ごとに、その行の幅に合う白い角丸背景**を付ける。2行では白い背景がつながり、行の長さに応じた段差ができる。一枚の固定幅カードにはしない。通常の黒文字に追加の影・縁はない。

720×1280の原見本では、本文の中心はおよそ(360,1079)、字面の高さ57〜58px、2行の間隔80px。白い背景の高さは1行98px、2行全体177px。これらは書き出し画像の実測目安であり、別の文章で全幅を固定する値ではない。1080×1920へ配置するときも比率を保ち、顔・手元・画面端との関係を合成画面で確認する。

重要な発言を強調するときはW7の赤文字・白い縁・黒い影とし、白い角丸背景を外す。見本は0.5秒の「プロジェクションスラム」で入場する。[動きの比較画像](../assets/a04-reference/emphasis-motion.jpg)では、下から現れた文字の背後に拡大した半透明の複製が広がり、消えて静止文字が残る。映像そのものをズームさせない。利用できる同じ効果、または編集可能なMGで近づけ、曲線まで一致していない場合は近似と伝える。今回の発話に合う強調箇所を選び、冒頭へ警告文を強制しない。

フォントファイルはW6/W7と同定済みだが、TTC内のface番号は元データに指定がない。ファイル名の一致と描画の完全一致を分け、利用者の環境で使えるフォント・face・字幅を比較する。フォント本体は同梱していない。

`originalCapCut`のsize10/12、clip倍率1.5、背景角丸0.4、余白0.28、影・縁などは**CapCut固有単位**。そのままCSSのpx値へ入れない。原見本の画素計測と元データを分けて使い、実際の字面・背景幅・影を較正する。通常文字へ、無効なトップレベル影設定を誤って適用しない。

## 効果音は短く、発話を邪魔しない

音色・余韻・音量、発音位置、実際のミックスの確認は[効果音の共通手順](sound-effects.md)を使う。A04の原見本の強調・締めという役割は維持する。

見本の元データには、強調用「冲击-997531」と締め用「キラーン　金属　流れ星　テロップ　魔法」の2件がある。参照時刻・音量・公開カタログの識別子は`audio.referenceSfx`へ保存した。解析したPCでは原ファイルを読めたが、音源本体や私的キャッシュのパスは配布しない。元動画と音源の聴き比べは未実施で、同じ音を再現できたとは扱わない。

今回の環境で正規に使える原音を確認する。原音がなければ、許可された範囲で**費用のかからない類似の短い効果音**を探してよい。類似音は完全一致と呼ばず、選んだ音源と入手元を記録する。有料生成やBGMへ切り替えない。使える音がなければ「効果音は未追加」と伝え、発話と字幕の編集は進める。

強調音は今回の強調文字の出始め、締め音は実際の締めの発言へ合わせる。元の1秒・86.47秒へ固定せず、全テロップへ鳴らさない。元音量0.1071／0.0561は初期比較値にとどめ、現在のツールの音量単位を確認し、声が明瞭に聞こえるよう試聴して調整する。

## 原文資料と検証範囲

`referenceCues`は元データの全61画面文・時刻・生のデザイン値。`sourceScript`が示す通り、原音を確認したASR逐語録でも、今回採用する台本でもない。語句・改行・表示順を新しい素材へそのまま割り当てない。

元動画と元データは、87.97秒・61文字区間・縦横比・代表字幕・強調の動きが対応している。全2639フレームの差分を走査し、大きな画替わりは見つからず、末尾の黒画面もない。ただし全61原文の画面照合と音声の試聴は未完了。0.7.2では新素材1件でScriptによるフィラー・明らかな重複の整理、語尾復元、短い音声クロスフェード、字幕refresh後の残存文言修正、効果音と末尾の再同期、合成フレームを確認した。音声込みの全編連続再生、完成MP4、別利用者環境での一連の実行は未確認であり、この1件の語句・時刻を他素材へ固定しない。

文字だけ直す場合は該当字幕の文字・行別背景・字形を更新し、整理済みの映像・声・開始終了を維持する。誤字訂正にScriptの単語削除を使わない。発話をさらに切った場合は、字幕と効果音を実際の新時刻へ合わせ直す。字形を使うMGでは、文字入力だけで反映できずCodexによる字形・配置の更新が必要な場合がある。

完成時は全字幕、強調の入場、長い語句、つなぎ目、最初と最後を合成画面で確認し、全編を再生する。実施済みの確認と残る違いを伝え、MP4まで求められた場合は[ローカル保存](local-delivery.md)へ進む。
