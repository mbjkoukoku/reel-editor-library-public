# A08：院紹介・明朝帯＋本人の案内

「A8」はA08と扱う。主見本は「間地テンプレ1(1).mov」。[数値・レイヤー仕様](a08.json)と[画面原文](a08-script-reference.json)を読み、前半の紹介テロップと後半の本人発話を分けて編集する。A01の明朝だけ、A04の全文発話字幕だけ、A03の全音声ミュート、A07の患者役生成へ振り分けない。

## 最初の進め方

見本登録の依頼はLPなしで分析・登録する。別店舗の完成動画を作成済みとは扱わない。

通常の制作は、選択したA08と今回のLP・ホームページまたは確認済み店舗情報から始める。まず「前半の画面テロップ」「後半の本人の案内」「対応する映像」を短い表で提示する。後半の録画が未提供なら撮影用の台本案と明記し、実際の発言として扱わない。すでに元音声付き素材があれば、後半はその実発話を基準にする。

前半は見本の話順・短さ・語り口を保ち、地域・院の特徴・手法・利用条件などを今回確認できる事実へ差し替える。見本の「腰痛」「MSMメソッド」「根本から改善」「初回割引」などは、新店舗で確認できないまま流用しない。未確認なら該当欄を要確認とし、確認できる説明へ置換する。後半の割引や予約先も今回の実在する条件・導線で確認する。

台本だけを依頼された段階では映像編集を始めない。最後は「台本をご確認ください。内容が決まったら、施術・検査の素材と、ご本人が案内している元音声付き動画を、この同じタスクへ送ってください。AI音声の準備は不要です」と案内する。素材・文章・編集範囲がすでに承認済みなら、同じ承認を繰り返し求めず進める。新規AI音声を必須にしない。

## 元フォントとデザイン

両方とも元編集データとフォント実体を照合済みで、近似書体ではない。利用可能な同一フォントを使い、別の字体へ自動置換しない。OFL 1.1の原ファイル・著作権・ライセンスを[同梱フォント](../assets/a08-fonts/README.md)に保存した。別環境で同一のファイルを使っても、レンダラー差による文字組み・影の違いは合成で較正する必要がある。

| 区間 | 元フォント | 見た目 |
|---|---|---|
| 前半6区間 | Noto Serif JP Black / 900 | 白い太明朝、黒影、大きな中央配置、通常2行。触診の短文は1行 |
| 後半6区間 | Corporate Logo Rounded Bold ver3 / 700 | 小さめの白い丸ゴシック、黒影、画面下部中央、1〜2行 |

前半は文字と別に、幅いっぱいに近い半透明のグレーの角丸パネルを敷く。薄い明るい上縁と内側の陰影があるガラス風の見た目で、単なる黒い長方形とは違う。元パネルは800×357のPNGだが、その素材の再配布条件は未確認なので同梱しない。利用環境で正規に使える同素材があれば参照できる。そうでなければ編集可能な図形で角丸・透明度・ハイライトを再構成し、元画像と比較する。再構成を同一PNGと説明しない。

`a08.json`に各文字の元サイズ、拡大率、配置、行間・字間、影、部分強調の範囲を保存している。元のfont_size=15/10などはCapCut内部の値で、15px/10pxとして使わない。material全体とrichTextの影設定が食い違う箇所がある。特にshadow_distance=144とrichText distance≈8を単純に画面pxへ転記せず、実際の見本の影を根拠に調整する。`has_shadow=false`だけを見て、見えているrichTextの黒影を消さない。

テロップは前半・後半とも1行8文字以内・最大2行にしてください。句読点・英数字も1文字として数え、意味の区切りで改行してください。8文字×2行に意味よく収まらない文章は、次のテロップへ意味単位で分割し、各表示区間に読める時間を確保してください。3行にしたり、フォントサイズ・横幅・行間を縮めて詰め込んだりしないでください。見本の書体と基準サイズを保ち、行と行の間に十分な余白を取り、文字と影が重ならず窮屈に見えないか実際の合成画面で確認してください。 原見本の表示原文・観測値は保存したまま、新規制作ではこの8文字・最大2行・行間のルールを優先する。院名・施術名などの固有名詞や承認済みの意味を保ち、語尾を枠で欠けさせない。字幕内容、スタイル、表示時刻、背景パネルを分けて保存し、文字だけの修正で映像や元声を切らない。

## 完成承認を反映した制作基準（0.10.3）

2026-11-08に、新素材で作成したA08の文字サイズ・行間・テロップの区切り方をユーザーが完成承認した。今後は `a08.json` の `productionDefaults` を制作基準にする。原見本の `captions`・`outputGeometry`・`a08-script-reference.json` は分析資料のまま保持し、承認後の表示基準で上書きしない。

| 項目 | 1080×2336での承認基準 |
|---|---|
| 前半 | Noto Serif JP Black 900、125px、字間0、文字領域幅1032px、帯高さ520px |
| 終盤 | Corporate Logo Rounded ver3 Bold 700、107px、字間0、字幕アセット1080×440px、上端y=1572px |
| 行間 | 前半・終盤ともlineHeight 1.20（行高は文字サイズの1.20倍） |
| 文字の分け方 | 1行8文字以内・最大2行。意味単位で次のテロップへ切り替え、各区間に読める時間を確保 |

書体の表示名と描画時のfamilyは分ける。前半はpreferred family（name16）`Noto Serif JP` とweight 900、終盤の元書体は `Corporate Logo Rounded ver3` とweight 700。`Black`・`Bold`を含む書体表示名をそのままCSS familyへ決め打ちせず、現在のレンダラーへの登録名を確認する。承認環境の互換版だけは実行時family `A08 Corp Round Full` を使う。

同じ縦横比の別解像度では、文字・幅・帯・位置を基準キャンバスに対して同倍率で換算し、lineHeightは1.20を保つ。別比率では人物・手元・文字の安全領域に合わせて配置を再較正する。文字が多いことを理由にフォント・横幅・行間を縮めない。短い条件、特徴や手法の説明、次の案内などを一つの意味単位にし、一つの文章が長ければ次の表示区間へ順に分ける。元の語順と意味は保つ。承認例の店舗文言・テロップ数・完成秒数は新案件へ固定しない。

承認環境の終盤は、元Corporate OTFの読み込み失敗に対し、同一字形と送り幅を保って再ビルドした `A08 Corp Round Full` を使用した。同梱の `A08CorpRound-full.otf` は、その互換用派生版。元書体を正常に読み込める環境では元フォントを使い、独自の実行時ファミリー名を全利用者へ必須にしない。互換版の全10,062 Unicode対応・アウトライン・送り幅は照合済みだが、全OpenType組版機能や全OSでの描画一致を保証するものではない。[フォントの由来・OFL](../assets/a08-fonts/README.md)を確認し、最終的な文字・影・行間を合成画面で確かめる。

完成承認、編集可能な合成、ローカルMP4と字幕・切替の確認、音声の数値照合を確認した制作例を基準にした。直接の音声込み全編試聴や、別利用者の環境での導入から保存までは未検証として区別する。

## カットとアニメーション

元編集データは全7映像が等速。トランジション、文字アニメーション、キーフレームは設定されていない。動きは実映像の動作であり、文字は時刻で切り替わる。別パターンのタイプライター、ポップ、ズーム、フェード、派手な効果を追加しない。

素材の開始・途中・終わりを実際に確認し、施術者と施術動作が分かる部分を使う。無人の床・壁で時間を埋めない。説明や検査の意味を変える速度変更はしない。本人発話にある不要なフィラー、明らかな言い直し、長い間だけは[speech-cleanup.md](speech-cleanup.md)で自然に整理し、完成時刻へ字幕を合わせ直す。前半の施術動作を無音だけで自動削除しない。

実在の患者の顔は[face-mosaic.md](face-mosaic.md)で隠す。見本には患者が映るが、登録用の元見本と、新素材で必要な顔モザイクの確認は別である。顔の移動、横顔、反射、トリミング、切替と修正版MP4まで確認する。

## 音声

元編集では、映像クリップ自体の音量は0で、別の抽出音声1本と効果音2本を配置している。これは新素材でも全音声をミュートする指示ではない。後半は今回の本人声を残し、別トラックに同じ声を採用する場合だけ重複したカメラ音声を消す。

元音声のローカルASR2モデルは約16.56秒以降の案内を認識した。前半の6テロップは発話の逐語録と扱わない。締めの原字幕「ご連絡ください」とASR「ご覧ください」も異なるため、元字幕を検証済みの逐語録と呼ばない。今後の後半字幕は今回の原音で語句・時刻を確かめる。

整体院に合う無料BGMを選んで入れてください。落ち着き・清潔感・親しみやすさを基準に、公式配布元で商用のSNS動画への組み込みとカット・音量調整・フェードの利用条件を確認し、必要なクレジット表記も残してください。本人の声を邪魔しない音量に調整し、終わりは自然にフェードアウトさせ、曲名・作者・配布元・利用条件を制作記録に残してください。有料音源の購入・有料生成は行わず、今回BGMなしと指定された場合はその指定を優先してください。 BGM音源本体は配布スキルに同梱せず、案件ごとに公式配布元から取得する。

原見本の短い効果音は、案内の強調（元20.3秒付近）と連絡導線（元24.27秒付近）の役割。今回利用できる許諾済み音源があれば控えめに配置し、本人声を邪魔しない音量へ調整する。元音源本体は共有配布しない。音源の許諾がない状態で旧BGM・効果音を抜き出して別店舗へ流用しない。有料生成や購入へ暗黙に進めず、AI音声・BGMを新規生成しない。無料配布BGMの選定・追加は上記の既定手順で行う。音声なしという今回の明示指定があればそれを優先する。
