# 動画編集ライブラリ｜共通版を使う

A01〜A08の見本に沿って、CodexからChatCutを編集する共通プラグインです。A01〜A03はLPと依頼文から台本を確認してから素材を送ります。A04は最初から依頼文と元音声付き素材動画を送ります。A05はLPで短い画面テロップ・院名・配色を確認してから、施術前後の素材動画を送ります。A06は依頼文と元音声付き素材動画から始め、発話の要点をデザイン化します。A07はLPから画面台本と場面表を確認し、施術者の実写と調達・生成した患者役素材を組みます。A08はLPで前半の画面台本と後半の撮影用案内文を確認し、施術・検査と本人の元声付き呼びかけを組みます。案内版は0.10.8です。

詳しい導入と制作手順は [初心者向け手順](初心者向け手順.md) を読んでください。公開URLからの依頼、初回導入、ChatCutの接続、フォント、MP4保存まで案内しています。A07は依頼文に初回導入も含むため、別の設定依頼は不要です。

声の一部だけを直す場合も、BGMを保つ手順を共有しています。元の声とBGMが別素材で残っているかを先に確認し、声だけを編集します。

## 共有するもの

更新は [共通の配布元](https://github.com/mbjkoukoku/reel-editor-library-public) に保存します。各利用者が、その同じ版を自分のCodexへ導入して使います。作成者のMacや過去の会話は不要です。サイトの閲覧・コピーと公開GitHubからの取得には、招待もGitHubログインも不要です。Codex・ChatCutへの本人ログインと、必要なインストール操作は各自の環境で行います。

## 見本を選んで依頼する

A07は今回の承認済み完成版を制作の基準にしました。サイトで約49秒の完成例を確認でき、元の参考動画も開けます。本文78px・行高104px、静かめのBGMと目覚まし等の効果音、帰宅後の家事から旅行への気持ちまでを引き継ぎます。尺・院名・患者役は今回の素材とLPに合わせます。

[見本サイト](https://seitai-reel-library.ryo60129109.chatgpt.site/)でA01〜A08から選び、依頼文をコピーします。サイトが開けない場合は [A01](requests/A01-reference.txt)・[A02](requests/A02-reference.txt)・[A03](requests/A03-caption-only.txt)・[A04](requests/A04-speech.txt)・[A05](requests/A05-before-after.txt)・[A06](requests/A06-speech-design.txt)・[A07](requests/A07-patient-vlog.txt)・[A08](requests/A08-promo-speech.txt)の完全な依頼文を使えます。

- **A01/A02**：LP＋依頼文 → 台本確認 → 音声と素材動画を送付 → 発話に合わせて編集。
- **A03「施術風景・縦書きテロップ」**：LP＋依頼文 → テロップ台本確認 → 素材動画だけ送付 → 全音声なしで編集。

- **A06「話の要点・コーラル帯デザイン」**：依頼文＋元音声付き素材動画 → 発話を分析 → 短い要点を見本のデザインへ配置 → 画面と元声を確認。逐語字幕は付けません。LPは任意、読み上げ台本・AI音声は不要です。

- **A08「院紹介・明朝帯＋本人の案内」**：LP＋依頼文 → 前半の画面台本・後半の撮影用案内文を確認 → 施術・検査と本人の呼びかけの元音声付き素材 → 見本と比較して編集。新規AI音声は不要です。

## 映像を編集するとき

**A01/A02**は、台本が決まって素材と音声が届いたら、実際の発話へカットと文字を合わせます。新たなAI音声・BGMは標準では生成しません。本人の発話をそのまま使う場合は、[A01発話用](requests/A01-speech.txt) または [A02発話用](requests/A02-speech.txt)を使えます。

**A03**は、確認したテロップ台本と素材動画だけで進めます。施術者や施術の動きが見える場面を選び、文字を読める長さに調整します。素材音声も含め全音声をミュートし、文字起こし（ASR）やフィラー・無音を基準とするカットは行いません。見本の秒数へ固定する必要はありません。

**A04**は、素材の元声を使います。意味のある返答・自然な息継ぎ・語尾を残し、不要なフィラーや長い間、明らかな言い直しだけを整理します。完成した自然な1回を残し、専門語・固有名詞・文末表現を単語境界で切り詰めません。Script反映後に完成側を再読し、変更したつなぎ目を一文として再生してから、テロップ・SFX・末尾を新しい時刻へ合わせます。短い効果音（SFX）は、正当に使える原音があれば使用し、なければ費用なしで使える類似素材を選びます。類似素材を見本と同一の音とは呼びません。新しいBGMや有料AI生成は使いません。

**A05**は、素材の記録と説明で前後の対応を確認します。画角・大きさ・動作を揃えた「施術前 → 施術後」を基本にし、横並びは比較しやすい場合だけ使います。患者の顔をモザイクで覆い、移動・横顔・反射・画面切替・トリミング後まで確認します。LPの色を見出しへ使い、文字ラベルとコントラストで前後を区別します。見本の約47.8秒へ固定せず、検査・動作に必要な時間を残します。元音声は今回の指定に合わせて扱い、音声なしの指定があればミュートします。

**A06**は、時刻付きで分析した実発話から、短いテーマや要点を選んでデザインへ配置します。LPは院名・予約先などの確認用で任意です。要約を本人の引用にはせず、見本の文言や効果を今回の事実として流用しません。元声を残し、必要なカットだけ自然に整えて、施術・実演に必要な間は残します。新規AI音声・BGM・効果音は追加しません。患者の顔には共通手順のモザイクを使います。

A08は0.10.3で完成承認された文字サイズと行間を制作基準にしました。1080×2336では前半125px・終盤107px、行高1.20倍・字間0。別解像度では同倍率で換算し、テロップ数・秒数は固定しません。詳細はa08.jsonのproductionDefaultsを使います。

A08のテロップは1行8文字以内・最大2行とし、意味の区切りで改行します。収まらない文章は次のテロップへ分け、各表示区間に読める時間を確保します。3行・フォント縮小・行間詰めで押し込まず、行と行の間に余白を取り、実際の合成画面で文字と影が重ならないことを確認します。編集時は整体院に合う無料BGMを公式の商用SNS動画利用条件を確認して選び、本人の声を邪魔しない音量と自然なフェードで入れます。今回のBGMなし指定を優先します。

**A08**は前半の院紹介と後半の本人の案内を分けます。前半はNoto Serif JP Black 900と半透明グレー角丸帯、後半はCorporate Logo Rounded ver3 Bold 700の白い小字幕と赤強調を使います。2書体はOFLライセンス付きで同梱します。カットと字幕の切り替えを独立させ、素材の動き・発話へ長さを合わせます。本人声を保持し、患者の顔はモザイクで覆います。元データに文字アニメーション・キーフレーム・トランジションの設定はないため、派手な動作を追加しません。元1080×2336の画面を勝手に16:9へ切り抜かず、出力比率変更時は座標を確認します。許諾未確認の元BGM・SFXは配布せず、有料生成は追加しません。

A08は0.10.3で新素材の編集可能な合成・ローカルMP4・全テロップと切替・音声の数値照合を確認し、ユーザーが完成承認した文字サイズ・行間・区切り方を制作基準へ反映しました。本人声の同期、患者顔の追従、直接の音声込み全編試聴、別利用者環境での一連の操作は、この承認で検証済みになったとは扱いません。今回の明示依頼と承認済み内容を優先し、再承認を繰り返しません。

A01は0.4.4の元フォント合成確認・完成承認を反映した手順、A02は0.4.2の完成承認された最大2行・中央やや下・読みやすい縁と影を使います。A01/A02の元フォント本体は同梱していないので、各自が使えるフォントを確認します。A02前半の書体は承認済みの近似であり、原見本と同一と特定されたものではありません。A03はヒラギノW6/W7/W8、縦書きと横書きの使い分け、文字の強調・影を元見本から参照します。A03の新素材によるChatCutでの描画は未検証なので、最初の制作で見本と合成画面を比較します。

A04は本文のヒラギノW6と強調のW7を確認します。新素材1件でScriptによる発話整理、語尾の復元、短い音声クロスフェード、字幕とSFX・末尾の再同期、合成フレームを確認しました。音声込みの全編連続再生と完成MP4、別利用者環境での一連の実行は未確認です。

A05は今回の参考分析・編集パターンの登録です。新素材でのChatCut編集と、動く顔へのモザイク追従・完成MP4の確認は未検証です。最初の制作では前後の対応と、顔を隠せていることを全編で確認します。

A06は新素材1件で、発話内容と要点の対応、編集可能なChatCut合成、Noto Sans JP 900相当の近似字体、文字サイズ・字間・行間・カード余白、本文・終盤の代表画面、切替境界、最終フレームを確認し、利用者が完成承認しました。元見本の字体と同一とは扱いません。原音の独立試聴、音声込み全編連続再生、完成MP4、顔モザイクの全フレーム監査、別利用者環境の一連の実行は未確認です。

## 0.10.8の改善：音量・写真・説明動画の選び方

効果音の突出を抑え、写真の必要な部分を残して余白を減らします。実演がなく今回の指定で説明映像への代替が認められる場合は、実際に伝える動作のある区間を説明として使います。前後の動作・構図と既使用区間を比較し、同じ映像の不要な繰り返しを減らします。音量・倍率・秒数は案件ごとに判断します。
